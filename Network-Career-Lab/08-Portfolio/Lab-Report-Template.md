# 实验记录模板

复制到自己的 `evidence/Wxx/` 目录后填写。空白模板本身不算实验成果。

## 问题与边界

- 实验 ID / 日期 / 操作者：
- 类型：实机 / 虚拟功能实验 / 模拟数据 / 纸面设计
- 业务问题与成功条件（用可观测指标）：
- 环境、软件/驱动/固件版本：
- 拓扑与地址、接口、ASN、VLAN/VNI、租户：
- 不在本次验证范围的内容：

## 基线与假设

| 观测点 | 命令/工具 | 预期 | 实际 | 文件/截图位置 |
|---|---|---|---|---|
| 控制面 | | | | |
| 数据面 | | | | |
| 应用面 | | | | |

记录采样时间、单位和观测方向。性能数据需给出样本量、负载、重复次数、分位数；计数器注明累计值还是增量。

## 变更与故障注入

- 单一变更是什么，为什么预计会产生该现象：
- 注入前保存的配置 / 状态：
- 注入的确切命令与时间：
- 预期受影响路径与未受影响路径：
- 实际现象：
- 备选解释与排除证据：

## 恢复

- 恢复操作：
- 恢复后的协议、数据、业务验证：
- 临时进程/namespace/云资源清理清单：
- 是否回到原基线，未恢复项是什么：

## 结论与表达

用“证据支持……；尚不能证明……”写两句话。把事实与推测分开。

英文 60 秒提纲：*The expected path was … We observed … My first hypothesis was … The capture/counter showed … After reverting … The remaining limitation is …*
