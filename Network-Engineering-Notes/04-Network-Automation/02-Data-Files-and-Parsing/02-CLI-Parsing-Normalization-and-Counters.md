# CLI解析、状态归一化与计数器

[返回网络自动化目录](../Network-Automation.md)

## 1. 原始输出与统一模型分开

SSH拿到的show文本常为人类阅读设计，空格、分页、语言、固件和权限可能改变格式。优先使用平台支持的结构化输出；只能解析文本时，要按命令/版本保存脱敏Fixture和解析测试。

TextFSM、TTP或平台解析库可以帮助提取，但模板存在不代表适配所有版本。解析失败、无匹配和真正空表是三种状态，不能都返回空列表并宣布设备没有邻居。

## 2. 三层流水线

原始层保留命令、平台、版本、时间和受控原文；解析层提取字段；归一化层统一单位、状态与身份。例如UP/up/connected可能在特定上下文表示不同信息，不应不分admin/oper直接统一成True。

统一接口结构可包括device_id、interface_id、admin_state、oper_state、speed_bps、rx_bytes、tx_bytes、counter_bits、observed_at、collection_status。字段名和单位固定，未知用明确状态而非猜测。

## 3. 计数器计算

若tx_bytes两次分别为1000000、2500000，间隔10秒，平均速率为(2500000−1000000)×8/10=1200000bit/s，即1.2Mb/s。只对同设备、同接口、同计数语义且采样间隔有效时计算。

计数回落可能是重启、清零、接口重建、计数器回绕或采集错对象。没有位宽与重置证据，不应把负差值直接取绝对值。累计丢包不等于当前窗口丢包，错误率的分母也要定义。

## 4. 解析反例

| 输入情况 | 应得结果 |
|---|---|
| 正常两条邻居 | 两条完整记录 |
| 平台明确显示空表 | 成功且记录数0 |
| 命令被拒绝/不支持 | 命令错误，不是空表 |
| 截断/分页未完成 | 不完整结果，禁止用于删除判断 |
| 新版本列发生变化 | 解析失败/待适配，不静默填默认值 |

## 5. 练习

为同一个命令准备正常、空、拒绝、截断和格式变化五个Fixture。对输出Schema和关键字段写断言；把解析器版本与采集结果关联。原文含口令、社区串或个人数据时先脱敏并验证脱敏不破坏测试含义。

[TextFSM原始项目](https://github.com/google/textfsm)、[Python正则](https://docs.python.org/3/library/re.html)。正则适合有限格式提取，不是所有网络配置的通用语法树。
