# 光互联、FEC、Breakout与BOM核对

[返回本部分学习目录](../AIDC-and-RDMA.md)

## 1. 外形与能力分开

QSFP/OSFP等描述相应封装形式，400G/800G描述速率层次，电/光Lane、PMD、距离、连接器、光纤类型、极性与FEC共同决定链路。相同外形不保证两端互通，端口标800G也不保证任意2×400G拆分。

| 字段 | 核对内容 |
|---|---|
| 两端设备 | 端口硬件、固件、速率与兼容矩阵 |
| Lane/Breakout | 电/光通道、映射、连接器与子端口 |
| 介质 | DAC/AOC/可插拔光、距离和布线 |
| FEC | 模式、两端支持、纠错与不可纠错统计 |
| 工程 | 功耗、散热、弯曲半径、极性与标签 |
| 备件 | 可替换范围、交期和验证记录 |

## 2. FEC与错误

纠错计数并非一增长就必须换模块，需按厂商阈值、趋势、速率和不可纠错/业务影响判断。链路UP不代表质量稳定，光功率正常也不排除介质/FEC/固件问题。不要为减少延迟随意禁用FEC。

## 3. 采购与验证

BOM记录每条链两端、接口/料号、版本、长度、数量、冗余与备件，引用选定设备的官方兼容矩阵。动态价格和新型号需在采购时查证，本教材不给长期通用料号清单。

## 4. 验收

逐链记录协商、光学/电气状态、纠错与不可纠错、长时间负载、冷启动和重插结果。生产维护需正式窗口，不能通过反复拔光纤碰运气。

## 5. 练习

给服务器到Leaf和Leaf到Spine各填一份链路表，列未获得的兼容证据。光模块数量公式只在链路/拆分假设一致时适用，不能将Rail教学总数当报价单。
