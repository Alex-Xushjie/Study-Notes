# 终端入网、隔离与生命周期

[返回本部分学习目录](../Campus-and-Wireless.md)

## 1. 入网流程设计

从设备归属、注册、凭据/证书发放、网络选择到策略落地，明确每一步负责方与失败恢复。员工离职、设备丢失、外包到期和IoT退役都需撤销访问，不仅删除一条无线客户端记录。

访客需要赞助/有效期时，Portal、身份、短信或邮件可能成为依赖。故障时是否允许降级必须由组织策略确定，不能默认所有访客转员工权限。

## 2. IoT例外

部分IoT不支持企业EAP或现代安全方式，先核实功能，再选独立分区、受控密钥和出口白名单。兼容需求不应使整个员工SSID降级。设备升级、密钥轮换和供应商维护通道应纳入台账。

## 3. 隔离验收

| 测试 | 预期 |
|---|---|
| 访客到内部地址 | 按矩阵拒绝，避免仅DNS失败造成假拒绝 |
| 同AP/跨AP终端互访 | 符合客户端隔离目标 |
| IoT到非授权控制端 | 拒绝且日志可定位 |
| 身份撤销后重连 | 不再获得旧授权 |
| AAA不可用 | 按已批准模式降级/阻断 |

## 4. 隐私与台账

随机MAC导致资产关联变化，日志应结合授权身份、会话与设备管理标识。收集最小必要数据，保留与访问权限按组织要求，作品集用脱敏样例。

## 5. 练习

画一台BYOD从首次入网、证书续期到离网的流程，注入证书过期、NAC不可用和授权角色缺失。记录故障应停在哪一层，避免无限重试或永久放宽权限。
