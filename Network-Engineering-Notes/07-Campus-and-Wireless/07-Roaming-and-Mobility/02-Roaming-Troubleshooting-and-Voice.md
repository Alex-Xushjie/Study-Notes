# 漫游排障与语音连续性

[返回本部分学习目录](../Campus-and-Wireless.md)

## 1. 先判断漫游发生在哪里

用户说走动掉线，可能是RF覆盖断点、重新认证慢、VLAN/角色变化、DHCP续租、控制器移动路径或应用重连。对齐客户端与AP/AAA日志，确认旧/新BSSID和实际地址是否变化。

| 症状 | 区分证据 |
|---|---|
| 迟迟不切弱AP | 候选覆盖、终端扫描与决策 |
| 已换AP但认证慢 | EAP/RADIUS、缓存/FT与证书 |
| 认证成功无IP | VLAN映射、DHCP/Relay与角色 |
| IP不变仍单向 | 锚点、隧道、MAC/ARP与状态路径 |
| 网络恢复应用仍断 | 应用重试/超时与会话 |

## 2. 语音测量

使用受控语音/实时流，记录序号、丢包、突发间隔与主观/业务结果。DTIM、省电、WMM、RF重传和漫游都可能影响；平均RSSI或平均延迟不足以代表通话。

不同AP的抓包时钟未对齐时不能直接相减得微秒结论。无线监控抓包可能丢帧或只在某信道，说明采集能力，不把“没捕获到”直接判为帧未发。

## 3. 修复与回归

一次只改变布点/功率、漫游辅助或认证策略之一。验证原问题终端及旧/IoT终端，不能牺牲兼容性换单台测试机漂亮曲线。保留回退和变更前基线。

## 4. 交付练习

提交两AP漫游时间线，标注关联、安全、IP和应用四层。至少构造一个RF正常但AAA延迟的反例，说明为什么加AP不解决。
