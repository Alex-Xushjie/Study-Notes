# 接入口、PoE与维护恢复

[返回本部分学习目录](../Campus-and-Wireless.md)

## 1. 端口是一组依赖

终端连接失败可能来自线缆、协商、PoE、VLAN、认证、地址和业务权限。先确认端口角色：普通终端、AP、电话+PC、下挂交换机或基础设施。边缘保护、Trunk允许范围与认证不能全局同配。

| 观察 | 不能直接推导 |
|---|---|
| Link UP | VLAN、认证或服务已正常 |
| 已提供PoE | AP已完成启动且所有射频启用 |
| 端口允许某VLAN | 上联、网关与回程也完整 |
| MAC已学习 | 终端已取得正确IP和权限 |

## 2. PoE功率预算

区分PSE供电设备、PD受电设备、每端口能力、整机电源预算与协商。某AP在低功率下可能降射频/空间流/有线功能，行为按型号核对，不能仅看指示灯。线长、线质、端口功率策略和电源故障都影响实际能力。

教学例：24台AP按每台30W预算需720W，另有8台电话各8W需64W，合计784W；这只是给定设备输入预算，实际还要考虑分类、线损、冗余电源模式与平台可用功率。双电源失去一个后能否保持全部负载需实算。

## 3. 变更与恢复

AP升级重启、交换机升级、电源故障可能同时使大量终端重新认证和DHCP，造成恢复风暴。维护分批并保留AAA/DHCP容量。更换交换机时导出端口到终端映射和认证策略，不依赖现场人员记忆接线。

## 4. 验收

分别记录冷启动、单电源/上联故障、恢复后的供电、认证、地址和应用时间。只在授权实验设备测试断电。提交N-1电源和上联预算，以及关键AP/电话的保留策略。

[园区整体参考](https://www.cisco.com/c/en/us/td/docs/solutions/CVD/Campus/cisco-campus-lan-wlan-design-guide.html)。PoE等级、可用瓦数和降级行为查具体硬件数据表，不把教学30W当所有AP需求。
