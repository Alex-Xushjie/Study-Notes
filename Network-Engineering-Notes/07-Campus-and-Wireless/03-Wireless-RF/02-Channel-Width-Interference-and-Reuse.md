# 信道宽度、干扰与空间复用

[返回本部分学习目录](../Campus-and-Wireless.md)

## 1. 宽信道的代价

更宽信道在条件合适时提高峰值PHY速率，却消耗更多频谱、减少独立复用机会，也可能包含更差的子信道。高密度园区不应仅按单台跑分选择80/160MHz。20/40/80等规划需结合可用频谱、AP分布、终端与容量目标。

同信道竞争是多设备共享同一资源；邻信道/非Wi-Fi干扰可能造成不同影响。一个空口忙碌数值不能自动区分来源，需要邻居、重传、频谱和客户端证据。

## 2. 功率与复用

降低功率可缩小某些小区影响，但不代表越低越好；覆盖不足会使终端降速和重传，反而占更长Airtime。AP、终端和邻居必须一起观察。新增AP如果同信道过密，可能减少而非增加有效容量。

## 3. 自动射频管理

自动信道/功率管理利用观测调整资源，不是免现场设计。确认算法窗口、调整事件、DFS动作、黑名单与人工覆盖。故障时间若与信道变化吻合，还需验证因果，不能见到自动调整就关闭全网RRM。

## 4. 验证矩阵

| 条件 | 观察 |
|---|---|
| 低负载/单终端 | 链路上限与客户端能力 |
| 高密度/多终端 | Airtime、重传、应用与公平性 |
| 相邻会议室满员 | 穿墙同频影响与复用 |
| 信道变化/DFS事件 | 关联、扫描、业务中断 |

## 5. 练习

为同一楼层分别给出宽信道与较窄信道规划，写假设和取舍。真实对比使用相同终端/负载与位置，不以一次测速证明长期容量。频谱扫描需合法授权且不主动干扰他人网络。
