# 射频、RSSI、SNR与传播

[返回本部分学习目录](../Campus-and-Wireless.md)

## 1. 无线质量不只有信号格

RSSI描述接收信号强度，常以dBm表示；噪声底与RSSI差值构成SNR的常见估计。dBm是功率绝对量的对数表示，dB是比值。-55dBm比-75dBm强，但强信号也可能遭受竞争/干扰并重传。

教学例：RSSI=-65dBm、噪声=-92dBm，SNR约27dB。不同设备测量方法、时间和天线不同，不能把不同来源数值直接拼成精确链路预算。

| 因素 | 影响 |
|---|---|
| 距离、墙体、金属/玻璃 | 衰减、反射和多径 |
| 发射功率与天线 | 覆盖形状，不保证终端回传同样强 |
| 同信道其他网络 | 共享或竞争空口资源 |
| 非Wi-Fi干扰 | 可能损害接收但不显示为正常Wi-Fi邻居 |
| 客户端能力/姿态 | 天线、空间流、驱动与遮挡 |

## 2. 频段与信道

2.4/5/6GHz的可用信道、功率、室内/室外与DFS/AFC等要求受国家/地区、设备和监管约束。使用正确国家码与当地支持列表，不复制其他地区的信道或功率。频率更高不等于任何环境必然更差或更快，要结合距离、材料和能力。

## 3. 双向链路

AP听得见客户端、客户端听得见AP分别验证。把AP功率拉满可能让客户端保持在远端AP，客户端小功率回传仍差。天线方向、安装高度和终端持握要符合真实使用。

## 4. 练习

用同一型号终端在固定位置/方向采样RSSI、噪声、重传、速率与应用。改变位置和遮挡，而非同时改功率/信道/带宽。交付相对比较及测量限制，不把某单一RSSI阈值当全业务合格标准。
