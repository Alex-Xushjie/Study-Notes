# 可直接复用的设计与验收模板

[返回本部分学习目录](../Engineering-Reference.md)

## 1. 设计首页模板

| 字段 | 填写 |
|---|---|
| 项目/版本/日期 | 具体标识与时区 |
| 问题与目标 | 业务触发、影响与量化口径 |
| 范围/不在范围 | 站点、服务、系统边界 |
| 现状与依赖 | 拓扑、版本、责任方、共享服务 |
| 选定方案/备选 | 相同目标下的比较与理由 |
| 假设/未知 | 影响、验证与负责人 |
| 实施/恢复 | 窗口、分批、止损和回退 |
| 验收/运维 | 测试、监控、Runbook与移交 |

## 2. LLD对象表

| 对象ID | 站点/区 | 类型 | 参数/版本 | 来源/所有权 | 依赖 | 验证方法 |
|---|---|---|---|---|---|---|
| LAB-001 | 实验区 | 测试网关 | 按实际填写 | 设计版本/负责人 | 上联、DNS等 | 状态+业务 |

实际填接口、IP/ASN/VNI/RT、路由/策略、云资源ID等所需字段，不把所有项目强塞同一超宽表。秘密只记录受控引用，不放密码/私钥。

## 3. 测试卡

| 字段 | 填写 |
|---|---|
| Test ID/需求ID | 可追踪关系 |
| 环境/前置 | 版本、权限、初始状态与能力 |
| 输入/负载 | 包长、方向、用户/流量、时间 |
| 动作 | 精确对象、单变量与故障范围 |
| 预期 | 状态、业务、拒绝/恢复阈值及依据 |
| 证据 | 原始记录位置、采样点、时钟/误差 |
| 结果/边界 | 通过/失败/未测/N/A及原因 |
| 清理/恢复 | 原值、恢复验证与遗留项 |

## 4. 例外与签认

例外记录影响、临时缓解、风险接受人、到期与复测。签认设计不等于性能已测，PoC通过也不等于完成全部生产交付。每份材料明确当前状态和版本。

## 5. 练习

用同模板描述“缺回程导致单向”的失败测试，保留失败与修复后两组证据；不要只留下最终成功截图。
