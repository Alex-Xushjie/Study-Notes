# 跨领域案例与作品证据

[返回本部分学习目录](../Engineering-Reference.md)

## 1. 案例库按机制组织

| 案例 | 首选与替代假设 | 需要的证据 |
|---|---|---|
| OSPF邻接异常 | MTU/参数/网络类型/过滤 | 双端状态、报文与接口 |
| BGP有会话无业务 | 前缀/Next-Hop/策略/回程 | 收选装发、FIB与请求 |
| 无线关联无IP | 授权VLAN/DHCP/RF丢包 | 认证属性、端口与DORA |
| 云私有服务本地失败 | DNS/路由/权限 | 解析链、有效路径和服务响应 |
| VPN正常单向 | Selector/NAT/回程 | SA、计数和两端抓包 |
| 行情gap | 队列/NIC/Socket/记录器 | 同序号/窗口的多点证据 |
| RDMA并发差 | 热点/映射/反馈/端点 | 队列、ECN/PFC、端点与作业 |

每行是调查起点，不是给定答案。实际平台和业务条件决定哪个解释成立。

## 2. 案例最小包

背景与影响、拓扑/地址/版本、复现步骤、正常/失败数据、假设和反证、一个最小变更、验证/回退、未覆盖项。输出可在没有作者口头解释时复查，不只留一张成功截图。

## 3. 经验分级

纸面设计证明推理，离线测试证明相应逻辑，软件拓扑证明部分协议，硬件实验证明所测条件，生产项目证明真实范围内的实施/运营。作品明确标签，不把模拟写成生产或把团队成果全部写成个人。

## 4. 表达

用“问题—机制—证据—取舍—结果—限制”讲案例。量化结果带样本/窗口/负载和起止点，未测的不猜数字。英文表达可以练习同样结构，技术内容保持一致。

## 5. 练习

从主线选两个代表案例，另一领域选一个迁移案例，整理成HLD、RCA和可复现Artifact。内部地址、账号、客户和设备资产先按组织要求脱敏。
