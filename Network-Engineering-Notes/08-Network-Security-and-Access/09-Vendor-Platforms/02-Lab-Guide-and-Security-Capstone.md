# 安全接入实验与综合验收

[返回本部分学习目录](../Network-Security-and-Access.md)

## 1. 环境和范围

使用隔离设备/合法镜像与测试身份，数据包只在自有实验范围。先单设备策略/NAT，再站点VPN、远程用户、AAA与证书，最后HA和零信任迁移。不要为演示扫描/压测第三方或关闭生产防护。

## 2. 实验清单

| 阶段 | 内容 | 证据 |
|---|---|---|
| S1 策略 | App→DB允许、其他拒绝 | 双向会话、命中、目标与回程 |
| S2 NAT | 出站/发布/Hairpin | 转换前后地址与服务结果 |
| S3 IPsec | 两站点、Selector、MTU与Rekey | 双端SA/计数、业务和恢复 |
| S4 远程 | 测试用户、DNS/路由/MFA与撤权 | 连接不等于授权、拒绝证据 |
| S5 802.1X | 受管终端、角色、CoA/AAA故障 | 认证与实际落地 |
| S6 HA | 节点/上游/心跳/恢复 | 新旧TCP、UDP、VPN和残余风险 |

证书实验用独立测试CA和不含真实身份的证书，不能往生产终端安装任意根。没有对应设备/IdP时保留纸面推演。

## 3. 综合场景

总部、两个分支、混合云、员工/访客/IoT、远程运维用户。产出区/角色/应用矩阵、NAT与双向路由、证书/身份生命周期、VPN和ZTNA适用边界、HA容量及日志关联。

至少三份RCA：规则允许但回程失败、隧道UP但Selector/NAT错误、认证成功但授权VLAN不存在。另测账号撤权后活动会话，明确无法即时失效的部分。

## 4. 完成标准

成功和拒绝都可解释；故障定位有反证；回退经过实验；日志与Diff不含秘密；生产要求与演示分开。结课回答为什么“登录成功”“策略允许”“会话存在”都不等于真实业务可用。
