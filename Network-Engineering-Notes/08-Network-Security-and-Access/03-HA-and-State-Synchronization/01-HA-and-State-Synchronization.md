# 防火墙HA、状态同步与故障域

[返回本部分学习目录](../Network-Security-and-Access.md)

## 1. HA包含多个机制

设备健康、主备选举、心跳、配置同步、会话/NAT同步和路由收敛各自独立。双机显示同步不证明所有连接状态、加密SA和业务代理都同步。Active/Passive与Active/Active也有不同流归属和转发行为。

| 对象 | 需核实 |
|---|---|
| 心跳/选举 | 独立链路、故障判定、优先级和抢占 |
| 配置 | 同步范围、版本/授权与例外 |
| 会话 | TCP/UDP/NAT、代理与加密支持 |
| 链路/路径监测 | 监测对象是否代表真实业务 |
| 数据转发 | 虚拟身份、ARP/ND、MAC与路由更新 |

## 2. 分裂与共同故障

心跳断但两边仍可转发时可能形成Split Brain，平台需要相应仲裁/保护行为，不能泛化为一定停哪台。共享交换机、电源、许可证、错误配置和升级缺陷仍可能同时影响双机。

## 3. N-1能力

两台正常分担不代表剩一台能承载全部加密/检查/日志负载。考虑峰值pps、连接建立、隧道数和恢复风暴；故障时关键业务与可降级业务提前分类。

## 4. 练习

为节点掉电、单业务口故障、心跳故障、上游黑洞、进程失败和配置误推逐项写检测与转发行为。实验在隔离HA对执行，保留控制台和回退。观察业务而非只看主备角色变化。

具体同步范围需查目标厂商版本。本篇用机制拆解建立验收问题，不承诺所有HA都无损。
