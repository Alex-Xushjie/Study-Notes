# 远程接入运营、故障与离职撤权

[返回本部分学习目录](../Network-Security-and-Access.md)

## 1. 故障分层

| 现象 | 先区分 |
|---|---|
| 网关不可达 | 本地Internet、DNS、代理、服务监听 |
| TLS/证书失败 | 时间、链、名称、信任、检查代理 |
| 登录/MFA失败 | IdP、用户状态、策略与因素 |
| Connected无内网 | 地址重叠、路由、DNS、授权 |
| 仅大文件/会议异常 | MTU、传输回退、丢包/抖动 |
| 固定空闲后断 | 隧道/NAT/身份会话超时 |

不要让用户关闭证书校验或全部安全软件作为永久修复。必要的区分实验在授权测试终端、短窗口与明确恢复条件下做。

## 2. 可观测性

关联用户、设备、客户端版本、网关、会话ID、分配IP、登录时间与授权组；敏感日志按权限保留。公网地址不能单独代表用户身份，同一家庭/运营商NAT可能多人共享。

## 3. 容量与HA

并发用户、连接创建/MFA突发、加密/检查吞吐、地址池和授权席位分别评估。故障后网关切换是否要求重认证、新地址或新隧道，按版本验证；不要只看网关主备状态。

## 4. 生命周期

用户离职/设备丢失需要撤身份、证书/Token、活动会话及例外权限。禁用目录账号未必立即终结所有缓存会话，需验证撤销传播与会话期限。保留受控应急账号/流程并审计，不能让IdP故障自动变全员免认证。

## 5. 练习

模拟受控账号撤权、网关故障、家庭地址冲突和私有DNS失败。交付诊断脚本/收集清单、恢复Runbook和拒绝验证，不收集用户真实口令或MFA码。
