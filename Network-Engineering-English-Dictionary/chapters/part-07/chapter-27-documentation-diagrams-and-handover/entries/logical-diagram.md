# logical network diagram

**Network engineering term** · Chapter 27

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A diagram showing logical relationships such as subnets, routing, or security boundaries.

## Usage and distinctions

A logical diagram does not necessarily show every physical cable or rack location.

## Examples

> The logical diagram shows the routing domains.

> Update the diagram after the VLAN change.
