# low-level design

**Network engineering term** · Chapter 27

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A document or description specifying implementation details for a design.

## Usage and distinctions

Abbreviation: LLD. It should remain consistent with the architecture and approved changes.

## Examples

> The low-level design lists interface and addressing details.

> Verify the configuration parameters against the approved design.
