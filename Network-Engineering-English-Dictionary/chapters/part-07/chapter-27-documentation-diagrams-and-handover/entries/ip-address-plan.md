# IP address plan

**Network engineering term** · Chapter 27

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A record of how IP address space is allocated or intended to be used.

## Usage and distinctions

A plan can differ from the current operational state; reconcile changes.

## Examples

> The IP address plan reserves a subnet for management.

> Check the plan and IPAM record before assigning an address.
