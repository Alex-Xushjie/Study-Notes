# network documentation

**Network engineering term** · Chapter 27

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Recorded information describing a network’s design, operation, configuration, or support.

## Usage and distinctions

Documentation should identify ownership, version, scope, and review status.

## Examples

> Update the network documentation after the change.

> Keep the documentation accessible to the support team.
