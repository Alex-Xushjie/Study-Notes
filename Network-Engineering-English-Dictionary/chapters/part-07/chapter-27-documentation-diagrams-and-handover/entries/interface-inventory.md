# interface inventory

**Network engineering term** · Chapter 27

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A record of device interfaces and their relevant attributes or connections.

## Usage and distinctions

Record the collection date and source; automatically collected state can become stale.

## Examples

> The interface inventory lists the uplink ports.

> Update the remote device and port identifiers.
