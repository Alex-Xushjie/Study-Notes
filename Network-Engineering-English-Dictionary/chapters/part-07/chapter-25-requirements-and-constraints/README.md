## Quick review

1. Is an assumption a confirmed fact?
2. Is an out-of-scope dependency irrelevant?
3. What is the difference between a risk and an issue?
4. Does validating a requirement mean the implementation satisfies it?

**Answers**

1. No; it must be validated.
2. No; it can still affect the project.
3. A risk is uncertain; an issue is a current problem or unresolved matter.
4. No; implementation verification is a separate activity.
