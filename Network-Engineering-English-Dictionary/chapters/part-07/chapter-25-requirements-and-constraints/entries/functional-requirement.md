# functional requirement

**Network engineering term** · Chapter 25

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A statement describing what a system must do.

## Usage and distinctions

A functional requirement describes behavior; it does not by itself specify every quality attribute.

## Examples

> The network must connect the branch to the application.

> List the required communication flows.
