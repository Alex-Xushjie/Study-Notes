# requirement validation

**Network engineering term** · Chapter 25

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The confirmation that a documented requirement reflects the intended need.

## Usage and distinctions

Validating a requirement differs from verifying that an implementation satisfies it.

## Examples

> The stakeholder validates the availability requirement.

> Resolve ambiguity before using the requirement in the design.
