# design requirement

**Network engineering term** · Chapter 25

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A documented need or condition that a proposed solution must satisfy.

## Usage and distinctions

A requirement should be clear, traceable, and verifiable when possible.

## Examples

> The requirement specifies branch connectivity.

> Confirm the requirement with the stakeholder.
