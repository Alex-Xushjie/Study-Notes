# technical requirement

**Network engineering term** · Chapter 25

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A technical condition or capability a solution must provide.

## Usage and distinctions

Technical requirements should include applicable conditions and measurable criteria.

## Examples

> The technical requirement specifies redundant uplinks.

> Confirm how the requirement will be tested.
