# security requirement

**Network engineering term** · Chapter 25

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A condition or capability needed to protect a system, service, or information.

## Usage and distinctions

Security requirements should specify the relevant assets, controls, and context.

## Examples

> The security requirement restricts administrative access.

> Confirm authentication and logging requirements.
