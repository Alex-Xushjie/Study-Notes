## Key terms

| Word | Meaning |
| --- | --- |
| [API endpoint](entries/api-endpoint.md) | The interface at which an API operation is exposed. |
| [API request](entries/api-request.md) | A message invoking an API operation. |
| [API response](entries/api-response.md) | A message returned in response to a request. |
| [HTTP status code](entries/http-status-code.md) | A code indicating the category of an HTTP result. |

## Examples and usage

> Verify the endpoint and environment.

> Check the request method and parameters.

> Inspect the response status and body.

> Do not expose credentials in diagnostic logs.
