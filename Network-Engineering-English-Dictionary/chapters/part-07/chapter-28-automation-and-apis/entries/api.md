# application programming interface

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A defined interface through which software components exchange requests or data.

## Usage and distinctions

Abbreviation: API. An API is an interface, not a particular protocol or data format.

## Examples

> The script retrieves inventory through the API.

> Check the API version and authentication method.
