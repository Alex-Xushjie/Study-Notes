# API rate limiting

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A restriction on the number or rate of API requests.

## Usage and distinctions

Rate limits and retry headers vary by API; repeated immediate retries can worsen the condition.

## Examples

> The API returns a rate-limit response.

> Use the documented retry behavior.
