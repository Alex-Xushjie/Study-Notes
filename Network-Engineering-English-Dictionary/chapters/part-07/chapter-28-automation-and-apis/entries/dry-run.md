# dry run

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A mode that previews or simulates an operation without applying its intended changes.

## Usage and distinctions

Dry-run completeness varies by tool; it may not predict every runtime effect.

## Examples

> Run a dry run before the approved deployment.

> Review the proposed changes in the dry-run output.
