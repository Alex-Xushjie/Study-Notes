# REST API

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An API designed around principles commonly associated with Representational State Transfer.

## Usage and distinctions

REST describes architectural constraints; an HTTP JSON API is not automatically a fully RESTful implementation.
