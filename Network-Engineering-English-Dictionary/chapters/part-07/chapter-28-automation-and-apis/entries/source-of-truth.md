# source of truth

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An agreed authoritative record for a defined category of data.

## Usage and distinctions

Authority should be defined per data domain; no single source is automatically correct for every fact.

## Examples

> The IPAM system is the source of truth for address allocation.

> Reconcile the record with the observed device state.
