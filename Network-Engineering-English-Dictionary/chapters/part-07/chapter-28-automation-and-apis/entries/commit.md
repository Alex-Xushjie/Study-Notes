# version-control commit

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A recorded snapshot or change in a version-control system.

## Usage and distinctions

A commit records source state; it does not necessarily mean the change has been deployed.

## Examples

> The commit records the inventory update.

> Reference the commit in the change request.
