# configuration drift

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A difference between observed configuration and an agreed intended or recorded state.

## Usage and distinctions

A difference is evidence to investigate, not automatically an unauthorized change.

## Examples

> The audit detected configuration drift.

> Determine whether the observed difference is authorized.
