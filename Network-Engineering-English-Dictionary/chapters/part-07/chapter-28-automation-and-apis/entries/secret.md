# automation secret

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Sensitive authentication or cryptographic material used by an automated process.

## Usage and distinctions

A secret should be protected, scoped, rotated, and handled according to organizational policy.

## Examples

> The pipeline retrieves the API credential from a secret store.

> Do not print the secret in logs.
