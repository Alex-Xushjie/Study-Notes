# HTTP status code

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A three-digit code indicating the result category of an HTTP response.

## Usage and distinctions

Status codes must be interpreted with the API and response context.
