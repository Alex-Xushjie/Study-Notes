# HTTP method

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A token identifying the intended semantics of an HTTP request.

## Usage and distinctions

Methods such as GET, POST, PUT, PATCH, and DELETE have defined semantics, but individual APIs may impose additional behavior.

## Examples

> The client uses GET to retrieve the resource.

> Check the documented method before sending the request.
