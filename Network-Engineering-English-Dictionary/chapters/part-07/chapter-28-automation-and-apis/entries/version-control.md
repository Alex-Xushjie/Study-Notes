# version control

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A system for recording and managing changes to files over time.

## Usage and distinctions

Version history and review controls improve traceability but do not guarantee a correct change.

## Examples

> The team stores the configuration templates in version control.

> Review the proposed changes before merging them.
