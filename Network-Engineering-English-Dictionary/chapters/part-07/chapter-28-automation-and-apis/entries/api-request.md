# API request

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A message sent to an API to invoke an operation or obtain information.

## Usage and distinctions

Requests may change state or be read-only; inspect the operation’s documented behavior.

## Examples

> The API request asks for the device inventory.

> Record the request method and parameters without exposing credentials.
