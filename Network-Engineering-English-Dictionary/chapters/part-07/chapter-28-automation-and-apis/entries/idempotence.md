# idempotence

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A property in which repeating an operation has the same intended effect as performing it once.

## Usage and distinctions

Idempotence does not mean an operation has no side effects on its first run.

## Examples

> The task is designed to be idempotent.

> Test a second run and compare the resulting state.
