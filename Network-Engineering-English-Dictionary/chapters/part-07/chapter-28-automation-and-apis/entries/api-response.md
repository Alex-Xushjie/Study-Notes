**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A message returned by an API in response to a request.

## Usage and distinctions

A successful response status does not automatically validate the correctness of all returned data.
