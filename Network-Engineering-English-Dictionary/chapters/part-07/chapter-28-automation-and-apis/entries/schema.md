# data schema

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A specification describing the structure or constraints of data.

## Usage and distinctions

A valid schema does not prove that the real network state matches the data.

## Examples

> The schema requires a device hostname.

> Validate the inventory against the schema.
