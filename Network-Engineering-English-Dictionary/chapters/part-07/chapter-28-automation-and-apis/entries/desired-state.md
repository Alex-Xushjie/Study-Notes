# desired state

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The configuration or condition that a system is intended to have.

## Usage and distinctions

Desired state must be current, validated, and scoped before automated enforcement.

## Examples

> The desired state specifies the approved VLANs.

> Compare the desired state with the observed state.
