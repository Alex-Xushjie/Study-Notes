# automation validation

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Checks that evaluate automation inputs, outputs, or effects against expected conditions.

## Usage and distinctions

Validation should include negative cases and observable postconditions where appropriate.

## Examples

> The workflow validates the inventory before connecting to devices.

> Verify the resulting device state after the change.
