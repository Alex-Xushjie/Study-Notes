# automation pipeline

**Network engineering term** · Chapter 28

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A sequence of automated stages used to validate, build, or deploy changes.

## Usage and distinctions

Pipeline permissions and deployment gates should match the environment and risk.

## Examples

> The pipeline validates the configuration template.

> Check the failed stage before rerunning the pipeline.
