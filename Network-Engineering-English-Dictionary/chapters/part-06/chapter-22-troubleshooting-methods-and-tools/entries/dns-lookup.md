# DNS lookup

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A query for DNS information associated with a name.

## Usage and distinctions

A lookup result depends on the resolver, cache, name, record type, and query time.

## Examples

> The DNS lookup returns an unexpected address.

> Check the resolver and record type used by the client.
