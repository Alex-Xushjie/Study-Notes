# remediation verification

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Checks performed to determine whether a corrective action achieved the intended outcome.

## Usage and distinctions

Verification should cover the original symptom and relevant regression checks.

## Examples

> Verify the application from the affected client after the change.

> Record the test result and time.
