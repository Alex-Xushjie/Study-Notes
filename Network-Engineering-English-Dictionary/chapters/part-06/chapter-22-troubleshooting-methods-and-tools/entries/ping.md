# ping

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A diagnostic test that sends echo requests and observes responses.

## Usage and distinctions

Ping results can be affected by filtering, rate limits, and endpoint handling; failure does not prove all traffic is blocked.

## Examples

> Ping the gateway from the affected host.

> Record loss and round-trip time.
