# isolate a fault

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

To narrow an investigation to a smaller component, path, or condition.

## Usage and distinctions

Isolation is a conclusion supported by tests; it should not be assumed from one symptom alone.

## Examples

> The team isolated the issue to one uplink.

> Compare an affected path with a known-good path.
