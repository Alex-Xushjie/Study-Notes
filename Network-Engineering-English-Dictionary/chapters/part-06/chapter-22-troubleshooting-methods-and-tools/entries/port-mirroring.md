# port mirroring

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A switch function that copies selected traffic to a monitoring destination.

## Usage and distinctions

Mirroring can omit or drop traffic due to configuration or destination capacity; platform behavior varies.

## Examples

> Configure an approved mirror session for the affected port.

> Check the source, direction, and monitoring port.
