# contributing factor

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A condition that helped produce or worsen an incident.

## Usage and distinctions

An incident can have multiple contributing factors and dependencies.

## Examples

> Missing monitoring was a contributing factor.

> Record contributing factors separately from observed symptoms.
