# interface errors

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Counters or events indicating interface-related receive or transmit problems.

## Usage and distinctions

Error counters are symptoms; a cable fault is one possibility among several.

## Examples

> The input error counter increases during the test.

> Record the counter definitions and interval.
