# route lookup

**Network engineering term** · Chapter 22

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process of determining which route or forwarding entry applies to a destination.

## Usage and distinctions

A control-plane route view and the actual forwarding decision can differ by platform.

## Examples

> Perform a route lookup for the server address.

> Check the lookup in the correct VRF.
