## Key terms

| Word | Meaning |
| --- | --- |
| [ping](entries/ping.md) | A diagnostic echo request and response test. |
| [traceroute](entries/traceroute.md) | A method that probes hops toward a destination. |
| [DNS lookup](entries/dns-lookup.md) | A query for DNS information. |
| [diagnostic packet capture](entries/packet-capture-troubleshooting.md) | A recording of packets at a specified observation point. |

## Examples and usage

> Ping the gateway from the affected host.

> Compare traces from the affected and working sites.

> Check the DNS resolver and record type.

> Record the packet capture location and time.
