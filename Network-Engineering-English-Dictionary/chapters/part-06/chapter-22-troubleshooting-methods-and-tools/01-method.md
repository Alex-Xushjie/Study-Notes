## Key terms

| Word | Meaning |
| --- | --- |
| [incident symptom](entries/symptom.md) | An observable indication of unexpected behavior. |
| [incident scope](entries/scope.md) | The boundaries of the affected users, services, locations, or time. |
| [troubleshooting hypothesis](entries/hypothesis.md) | A proposed explanation that can be tested. |
| [remediation verification](entries/verification.md) | Checks that evaluate a corrective action. |

## Examples and usage

> Describe the symptom and its scope before changing the network.

> State the expected observation before running the test.

> Compare the affected path with a known-good path.

> Verify the original symptom after the corrective action.
