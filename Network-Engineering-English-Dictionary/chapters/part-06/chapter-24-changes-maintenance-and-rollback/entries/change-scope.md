# change scope

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The systems, actions, and boundaries included in an approved change.

## Usage and distinctions

Scope should distinguish included actions from exclusions and related dependencies.

## Examples

> The change scope covers one branch router.

> Escalate if the work must exceed the approved scope.
