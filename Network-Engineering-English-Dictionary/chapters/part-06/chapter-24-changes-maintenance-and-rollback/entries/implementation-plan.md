# implementation plan

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The ordered actions required to carry out a change.

## Usage and distinctions

A plan should include owners, prerequisites, checkpoints, and references to rollback.

## Examples

> The implementation plan lists each configuration step.

> Review the commands and expected results in advance.
