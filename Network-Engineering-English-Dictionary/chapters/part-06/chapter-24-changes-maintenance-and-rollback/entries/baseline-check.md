# baseline check

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A measurement or verification of system behavior before a change.

## Usage and distinctions

A useful baseline includes timing, measurement points, and expected behavior.

## Examples

> The baseline check records latency and interface status.

> Compare the post-change results with the baseline.
