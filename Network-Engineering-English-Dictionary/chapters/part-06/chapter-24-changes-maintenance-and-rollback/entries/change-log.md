# change log

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A record of changes made to a system or service.

## Usage and distinctions

A change log should distinguish planned work from actions actually performed.

## Examples

> Update the change log with the implementation time.

> Record deviations from the approved plan.
