# network change

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A planned or unplanned modification to a network system or its configuration.

## Usage and distinctions

A change can affect multiple dependencies even when the configuration edit is small.

## Examples

> The change updates the routing policy.

> Document the scope and expected impact.
