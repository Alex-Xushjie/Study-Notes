# configuration backup

**Network engineering term** · Chapter 24

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A saved copy of a device configuration for recovery or reference.

## Usage and distinctions

A saved configuration may not include every system state or credential needed for recovery.

## Examples

> The team created a configuration backup before the change.

> Verify that the backup can be accessed and used.
