# time of detection

**Network engineering term** · Chapter 23

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The time when a problem was first detected by a person or monitoring system.

## Usage and distinctions

Detection time may be later than the actual start of the problem.

## Examples

> The time of detection was 09:15 UTC.

> Compare the detection time with the first user report.
