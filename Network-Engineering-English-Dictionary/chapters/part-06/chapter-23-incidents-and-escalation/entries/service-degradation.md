# service degradation

**Network engineering term** · Chapter 23

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A reduction in service quality or performance while some service remains available.

## Usage and distinctions

Degradation and complete outage have different user impact; use the organization’s definitions.

## Examples

> Users report degraded application performance.

> Measure the affected transaction and response time.
