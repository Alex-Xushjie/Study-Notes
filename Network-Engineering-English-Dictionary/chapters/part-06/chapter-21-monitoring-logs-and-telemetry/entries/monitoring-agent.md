# monitoring agent

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Software that gathers or forwards monitoring information from a system.

## Usage and distinctions

Some monitoring systems collect data without installing an agent on the monitored device.
