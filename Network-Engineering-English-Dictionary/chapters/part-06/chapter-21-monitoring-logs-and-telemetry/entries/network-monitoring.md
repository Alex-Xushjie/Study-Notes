# network monitoring

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The collection and examination of network state and measurements over time.

## Usage and distinctions

Monitoring provides evidence, but an alert alone does not establish root cause.

## Examples

> The monitoring system reports an uplink failure.

> Check the monitoring data for the incident window.
