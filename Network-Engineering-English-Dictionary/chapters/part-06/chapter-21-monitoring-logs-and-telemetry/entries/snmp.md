# Simple Network Management Protocol

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol family used to exchange network management information.

## Usage and distinctions

Abbreviation: SNMP. Versions provide different security capabilities; configuration must follow organizational policy.

## Examples

> The monitoring system polls the device using SNMP.

> Check the SNMP version and access configuration.
