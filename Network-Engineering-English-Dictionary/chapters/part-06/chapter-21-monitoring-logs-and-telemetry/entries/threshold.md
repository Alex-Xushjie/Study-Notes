# monitoring threshold

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A configured value or condition used to evaluate a measurement.

## Usage and distinctions

A threshold should specify unit, duration, aggregation, and context.

## Examples

> The alert threshold is set for sustained high utilization.

> Check the threshold and evaluation interval.
