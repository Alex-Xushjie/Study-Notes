# monitoring polling

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Periodic requests for measurements or state from a monitored system.

## Usage and distinctions

Polling can miss short events between samples and may add load.

## Examples

> The monitoring system polls interface counters every minute.

> Check the polling interval and timeout.
