# interface error rate

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The rate or proportion of interface errors over a defined interval.

## Usage and distinctions

An absolute error count is different from a rate; denominator and time window matter.

## Examples

> The interface error rate increased during peak traffic.
