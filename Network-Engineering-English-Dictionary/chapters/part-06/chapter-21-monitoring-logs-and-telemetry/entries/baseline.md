# performance baseline

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A reference set of measurements representing defined operating conditions.

## Usage and distinctions

A baseline depends on context and can change with traffic, topology, or service behavior.

## Examples

> Compare the current latency with the normal baseline.

> Document the workload and time period used for the baseline.
