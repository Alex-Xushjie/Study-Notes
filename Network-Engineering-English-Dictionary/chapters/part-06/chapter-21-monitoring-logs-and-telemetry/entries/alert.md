# monitoring alert

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A notification or state indicating that a monitored condition has met specified criteria.

## Usage and distinctions

An alert is a signal to investigate; it is not necessarily an incident or root cause.

## Examples

> The alert reports a sustained interface error rate.

> Check when the alert started and cleared.
