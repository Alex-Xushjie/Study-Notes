# monitoring event

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A recorded occurrence or state change observed by a system.

## Usage and distinctions

An event is an observation; its relationship to an incident requires investigation.

## Examples

> The event log records the interface transition.

> Correlate the event with the reported service impact.
