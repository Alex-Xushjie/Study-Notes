# system log

**Network engineering term** · Chapter 21

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A recorded message describing an event, state, or operation.

## Usage and distinctions

Logs can be incomplete, delayed, filtered, or use different time zones.

## Examples

> The device log shows an interface reset.

> Collect the log entries around the incident time.
