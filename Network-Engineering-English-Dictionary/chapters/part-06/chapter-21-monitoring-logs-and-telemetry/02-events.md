## Key terms

| Word | Meaning |
| --- | --- |
| [monitoring threshold](entries/threshold.md) | A condition used to evaluate a measurement. |
| [monitoring alert](entries/alert.md) | A notification that a monitored condition met criteria. |
| [monitoring event](entries/event.md) | A recorded occurrence or state change. |
| [system log](entries/log.md) | A recorded message about an event or operation. |

## Examples and usage

> Check the threshold and evaluation interval.

> The device log shows an interface reset.

> Correlate events using timestamps and time zones.

> An alert alone does not establish root cause.
