# authentication fallback

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A configured alternative authentication path used when the primary method cannot be used under defined conditions.

## Usage and distinctions

Fallback conditions and security implications must be explicitly defined; do not assume denial and server unavailability are equivalent.

## Examples

> The device has a documented authentication fallback.

> Test the fallback according to the approved procedure.
