# SSH host key

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A cryptographic key used by an SSH server to identify itself to clients.

## Usage and distinctions

A host key identifies the server; it is different from the user’s authentication key.

## Examples

> The SSH client verifies the host key before continuing.

> Investigate an unexpected host-key change.
