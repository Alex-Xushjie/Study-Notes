# Secure Shell

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol providing secure remote access and related services over a network.

## Usage and distinctions

Abbreviation: SSH. Access security depends on host-key validation, authentication, authorization, and configuration.

## Examples

> The engineer connects to the router using SSH.

> Verify the SSH host key according to the approved procedure.
