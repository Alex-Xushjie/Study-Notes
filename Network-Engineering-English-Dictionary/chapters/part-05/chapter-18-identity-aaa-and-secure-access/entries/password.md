# password

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A secret used as one possible authentication factor.

## Usage and distinctions

A password is a knowledge factor; its protection and lifecycle depend on the identity system.

## Examples

> The user signs in with a password.

> Follow the organization’s password-handling policy.
