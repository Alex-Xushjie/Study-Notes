# AAA server

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A server that provides one or more authentication, authorization, or accounting functions.

## Usage and distinctions

A reachable AAA server can still reject a request because of credentials, policy, or other conditions.

## Examples

> The network device sends the request to the AAA server.

> Check connectivity to each configured AAA server.
