# 802.1X authenticator

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The network access device that controls port access and relays authentication information.

## Usage and distinctions

The authenticator is distinct from the supplicant and the authentication server.

## Examples

> The switch acts as the 802.1X authenticator.

> Check the authenticator’s connection to the authentication server.
