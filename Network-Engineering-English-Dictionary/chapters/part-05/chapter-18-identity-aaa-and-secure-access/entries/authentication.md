# authentication

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process of verifying a claimed identity.

## Usage and distinctions

Successful authentication establishes an identity assertion; it does not by itself grant every permission.

## Examples

> The administrator authenticates with the identity service.

> Check the authentication result and error message.
