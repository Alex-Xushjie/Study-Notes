# Remote Authentication Dial-In User Service

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol commonly used to exchange authentication, authorization, and accounting information.

## Usage and distinctions

Abbreviation: RADIUS. Security properties and supported extensions depend on the deployment; verify current vendor guidance.

## Examples

> The switch sends an authentication request to the RADIUS server.
