# TACACS+

**Network engineering term** · Chapter 18

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol used for centralized device administration, including authentication, authorization, and accounting.

## Usage and distinctions

TACACS+ is specified in RFC 8907. Security and deployment behavior depend on the implementation and transport environment.

## Examples

> The router uses TACACS+ for administrator login.

> Check the TACACS+ server reachability and logs.
