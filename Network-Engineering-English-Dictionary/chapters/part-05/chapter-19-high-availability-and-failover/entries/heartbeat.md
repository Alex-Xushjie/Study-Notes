# HA heartbeat

**Network engineering term** · Chapter 19

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A periodic exchange used by components to monitor peer or system availability.

## Usage and distinctions

A heartbeat path and a state-synchronization path can be separate or combined depending on the design.

## Examples

> The firewalls exchange heartbeat messages.

> Check the heartbeat link and peer status.
