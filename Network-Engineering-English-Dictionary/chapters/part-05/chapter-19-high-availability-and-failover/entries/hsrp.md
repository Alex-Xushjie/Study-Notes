# Hot Standby Router Protocol

**Network engineering term** · Chapter 19

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A Cisco protocol used to provide a virtual gateway using multiple routers.

## Usage and distinctions

Abbreviation: HSRP. It is distinct from VRRP; configuration and version behavior are platform-specific.

## Examples

> The switches use HSRP for the default gateway.

> Check the active and standby state.
