# active-active

**Network engineering term** · Chapter 19

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A redundancy arrangement in which multiple components can actively handle traffic or services.

## Usage and distinctions

Active-active does not mean that every flow is active on every component; implementation details matter.

## Examples

> The application uses an active-active design.

> Check how traffic and state are distributed.
