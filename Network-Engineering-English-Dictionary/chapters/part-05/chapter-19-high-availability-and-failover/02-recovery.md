## Key terms

| Word | Meaning |
| --- | --- |
| [failover](entries/failover.md) | A transition to an alternate component or path. |
| [failback](entries/failback.md) | A return to a preferred component or path. |
| [recovery time objective](entries/recovery-time-objective.md) | A target for acceptable restoration time. |
| [recovery point objective](entries/recovery-point-objective.md) | A target for acceptable data loss measured in time. |

## Examples and usage

> The gateway fails over to the standby device.

> Confirm whether failback is automatic or manual.

> Define the measurement events for recovery time.

> Check whether the design meets the agreed RTO and RPO.
