# network throughput

**Network engineering term** · Chapter 20

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The rate at which data is successfully transferred over a defined interval.

## Usage and distinctions

Throughput depends on the measurement point, protocol overhead, loss, endpoints, and path conditions.

> The test measured 80 megabits per second of throughput.
