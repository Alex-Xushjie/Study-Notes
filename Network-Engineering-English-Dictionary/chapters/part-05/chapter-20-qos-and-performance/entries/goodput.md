# network goodput

**Network engineering term** · Chapter 20

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The rate of useful application data delivered, excluding some protocol overhead and retransmitted data.

## Usage and distinctions

Definitions vary by tool; compare measurements only when their scope is known.

## Examples

> The application goodput is lower than the interface throughput.

> Specify what the tool includes in its goodput measurement.
