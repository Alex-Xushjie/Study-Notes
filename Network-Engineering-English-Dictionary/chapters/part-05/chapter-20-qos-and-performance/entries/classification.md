# traffic classification

**Network engineering term** · Chapter 20

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process of identifying traffic according to configured criteria for subsequent treatment.

## Usage and distinctions

Classification can use addresses, ports, markings, applications, or other supported criteria.

## Examples

> The policy classifies voice traffic.

> Check which packets match the classification rule.
