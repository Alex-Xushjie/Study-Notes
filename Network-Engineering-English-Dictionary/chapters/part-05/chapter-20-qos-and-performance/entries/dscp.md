# Differentiated Services Code Point

**Network engineering term** · Chapter 20

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A field value in the IP header used to identify differentiated service treatment.

## Usage and distinctions

Abbreviation: DSCP. A DSCP value does not guarantee any specific treatment without an applicable policy.

## Examples

> The packet is marked with the expected DSCP value.

> Check whether the provider preserves the DSCP marking.
