## Key terms

| Word | Meaning |
| --- | --- |
| [source address](entries/source-address.md) | The address identifying a packet’s origin. |
| [firewall](entries/firewall.md) | A system applying rules to network traffic. |
| [destination address](entries/destination-address.md) | The address identifying the intended destination. |
| [security zone](entries/security-zone.md) | A logical grouping used for security policy. |

## Examples and usage

> Confirm the source and destination zones.

> The firewall policy permits HTTPS to the application.

> Check the session and rule counters.

> A permitted policy does not guarantee that the application works.
