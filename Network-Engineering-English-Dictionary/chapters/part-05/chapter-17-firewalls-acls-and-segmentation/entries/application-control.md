# application control

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A security function that identifies or controls traffic according to application-related information.

## Usage and distinctions

Identification accuracy and inspection depend on the product, traffic visibility, and configuration.

## Examples

> The policy applies application control to web traffic.

> Check how the firewall identifies the application.
