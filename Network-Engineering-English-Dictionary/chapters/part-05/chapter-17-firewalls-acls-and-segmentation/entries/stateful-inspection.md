# stateful inspection

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A filtering approach that tracks connection state when evaluating network traffic.

## Usage and distinctions

The exact state model and handling of asymmetric paths depend on the firewall.

## Examples

> The stateful firewall allows return traffic for the permitted session.

> Check the session table for the connection.
