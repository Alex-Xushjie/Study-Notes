# implicit deny

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A default policy behavior that denies traffic when no explicit rule permits it.

## Usage and distinctions

Default behavior is platform- and configuration-specific; do not assume all systems use the same default.
