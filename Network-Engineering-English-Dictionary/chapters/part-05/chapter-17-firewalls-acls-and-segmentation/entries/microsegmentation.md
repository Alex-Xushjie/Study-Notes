# microsegmentation

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A security approach that applies granular controls between workloads or small network groups.

## Usage and distinctions

Implementation can use host, hypervisor, network, or cloud controls; the precise boundary depends on the system.

## Examples

> The policy limits communication between application workloads.

> Identify the permitted workload-to-workload flows.
