# firewall network object

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A named policy object representing an address, subnet, or other supported network entity.

## Usage and distinctions

Objects improve reuse but an incorrect shared object can affect multiple rules.

## Examples

> The network object represents the application subnet.

> Check the current addresses in the network object.
