# network address translation

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The modification of IP address information in packets as they pass through a device.

## Usage and distinctions

Abbreviation: NAT. Source and destination translation serve different purposes; NAT is not a replacement for security policy.

## Examples

> The firewall performs network address translation at the edge.

> Compare the original and translated addresses.
