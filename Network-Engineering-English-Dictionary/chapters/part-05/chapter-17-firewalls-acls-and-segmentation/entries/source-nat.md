# source network address translation

**Network engineering term** · Chapter 17

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The translation of a packet’s source address and possibly transport information.

## Usage and distinctions

Abbreviation: SNAT. The exact translation and return behavior depend on the device and rule.

## Examples

> The firewall applies source NAT to outbound connections.

> Check the translated source address in the session.
