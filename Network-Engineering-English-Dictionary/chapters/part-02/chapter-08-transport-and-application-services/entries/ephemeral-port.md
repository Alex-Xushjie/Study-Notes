# ephemeral port

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A temporary local port selected for a communication endpoint, often by the operating system.

## Usage and distinctions

The actual ephemeral port range and selection behavior depend on the operating system and configuration.

## Examples

> The client opens a connection from an ephemeral port.

> Check whether the host has enough ephemeral ports available.
