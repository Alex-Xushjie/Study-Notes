# Dynamic Host Configuration Protocol

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol used to provide IP configuration information to clients.

## Usage and distinctions

Abbreviation: DHCP. DHCPv4 and DHCPv6 have different message formats and behavior.

## Examples

> The client obtains its IPv4 configuration through DHCP.

> Check the DHCP server and relay path.
