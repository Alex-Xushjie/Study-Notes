# User Datagram Protocol

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A transport protocol that sends datagrams without providing TCP-style reliable ordered delivery.

## Usage and distinctions

Abbreviation: UDP. Applications can implement their own reliability mechanisms above UDP.

## Examples

> The application sends a UDP datagram.

> Check whether the service expects UDP or TCP.
