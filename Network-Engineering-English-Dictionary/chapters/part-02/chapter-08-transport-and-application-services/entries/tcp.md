# Transmission Control Protocol

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A transport protocol that provides reliable, ordered delivery of a byte stream between endpoints.

## Usage and distinctions

Abbreviation: TCP. Reliability and ordering are properties of TCP’s byte stream, not guarantees that an application operation succeeds.

## Examples

> The client establishes a TCP connection to the server.

> Check for TCP retransmissions in the capture.
