# Hypertext Transfer Protocol

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An application-layer protocol for exchanging HTTP messages between clients and servers.

## Usage and distinctions

Abbreviation: HTTP. HTTPS uses HTTP over TLS; transport details can vary by HTTP version.

## Examples

> The client sends an HTTP request to the service.

> Check the HTTP response status and headers.
