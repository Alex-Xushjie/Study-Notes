# DHCP lease

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A time-limited assignment of an address or configuration by a DHCP server.

## Usage and distinctions

Lease duration and renewal behavior depend on the protocol version and server configuration.
