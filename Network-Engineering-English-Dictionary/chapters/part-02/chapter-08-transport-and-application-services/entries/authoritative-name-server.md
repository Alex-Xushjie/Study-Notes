# authoritative name server

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A DNS server that provides authoritative data for a zone.

## Usage and distinctions

An authoritative server serves zone data; it does not necessarily perform recursion for clients.

## Examples

> The authoritative name server returns the zone data.

> Verify the authoritative server for the domain.
