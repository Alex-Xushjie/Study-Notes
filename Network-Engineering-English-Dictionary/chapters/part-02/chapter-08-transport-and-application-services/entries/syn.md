# TCP SYN

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A TCP control flag used to synchronize sequence numbers when establishing a connection.

## Usage and distinctions

SYN is a TCP flag; a SYN packet can also contain options and, in some cases, data.

## Examples

> The client sends a SYN to start the connection.

> No SYN-ACK appears in the capture.
