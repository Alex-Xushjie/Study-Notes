# HTTPS

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

HTTP communication protected by Transport Layer Security.

## Usage and distinctions

HTTPS protects the connection in transit; successful TLS does not guarantee that the application itself is safe or correct.

## Examples

> The browser connects to the site over HTTPS.

> Verify the server certificate and host name.
