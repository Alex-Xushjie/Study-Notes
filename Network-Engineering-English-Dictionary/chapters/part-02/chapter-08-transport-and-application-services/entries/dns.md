# Domain Name System

**Proper noun; abbreviation: DNS.** · Chapter 08 · `technical`

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A distributed naming system that stores and retrieves resource records associated with domain names.

## Usage and distinctions

DNS stores more than address records. A recursive resolver and an authoritative name server have different roles.

## Common combinations

DNS query; DNS resolver; authoritative name server

## Examples

> The client can reach the server by IP address, but the DNS query fails.

> Which resolver did the client use for this query?
