# DNS AAAA record

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A DNS resource record that associates a name with an IPv6 address.

## Usage and distinctions

AAAA is pronounced as four letters or “quad A” in common usage.

## Examples

> The AAAA record contains an IPv6 address.

> Check whether the client received an AAAA answer.
