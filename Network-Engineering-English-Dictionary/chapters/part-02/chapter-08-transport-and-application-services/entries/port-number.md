# transport port number

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A number used by a transport protocol to identify an endpoint within a host.

## Usage and distinctions

A transport port number is a logical identifier, not a physical switch port. TCP and UDP have separate port spaces.

## Examples

> The client connects to the service on TCP port 443.

> Check both the protocol and port number in the policy.
