# destination port

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The transport-layer port number associated with the intended receiving endpoint.

## Usage and distinctions

A port number alone does not prove which application is running; ports can be configured differently.

## Examples

> The client sends the request to destination port 443.

> Check the destination port in the firewall rule.
