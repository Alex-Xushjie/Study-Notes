# TCP SYN-ACK

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A TCP response with both SYN and ACK flags set during the usual connection-opening exchange.

## Usage and distinctions

SYN-ACK acknowledges the initiating SYN and synchronizes the responder’s sequence number.

## Examples

> The server responds to the client with a SYN-ACK.

> Check whether the SYN-ACK reaches the client.
