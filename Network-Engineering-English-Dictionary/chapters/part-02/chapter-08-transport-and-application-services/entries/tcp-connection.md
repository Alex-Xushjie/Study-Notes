# TCP connection

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A transport association between two TCP endpoints that maintains state for a byte stream.

## Usage and distinctions

An established connection does not by itself verify authentication, correct application behavior, or data integrity at the application level.

## Examples

> The TCP connection is established.

> The TCP connection opens, but the application request fails.
