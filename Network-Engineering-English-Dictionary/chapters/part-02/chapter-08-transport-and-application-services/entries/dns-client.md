# DNS client

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A program or host function that sends DNS queries to obtain name-related information.

## Usage and distinctions

A client is often called a stub resolver; exact behavior varies with the operating system and application.

## Examples

> The DNS client sends a query to the configured resolver.

> Check which resolver the client is using.
