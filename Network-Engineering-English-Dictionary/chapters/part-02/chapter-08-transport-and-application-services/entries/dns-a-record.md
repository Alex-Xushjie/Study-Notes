# DNS A record

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A DNS resource record that associates a name with an IPv4 address.

## Usage and distinctions

An AAAA record is used for IPv6 addresses. A name can have more than one A record.

## Examples

> The A record points to 192.0.2.10.

> Verify the A record returned by the resolver.
