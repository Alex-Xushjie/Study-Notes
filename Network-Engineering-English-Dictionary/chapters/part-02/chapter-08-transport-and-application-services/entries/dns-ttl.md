# DNS time to live

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A value indicating how long a DNS record may be cached.

## Usage and distinctions

Abbreviation: TTL. Actual caching behavior can also be influenced by resolver policies.

## Examples

> The DNS record has a short time to live.

> Allow for cached answers when planning the change.
