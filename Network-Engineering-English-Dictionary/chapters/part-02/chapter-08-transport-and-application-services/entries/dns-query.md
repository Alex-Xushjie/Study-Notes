# DNS query

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A request for DNS information associated with a name and record type.

## Usage and distinctions

DNS queries commonly use UDP or TCP, depending on the exchange and configuration.

## Examples

> The resolver sends a DNS query for the host name.

> Check the query name and record type.
