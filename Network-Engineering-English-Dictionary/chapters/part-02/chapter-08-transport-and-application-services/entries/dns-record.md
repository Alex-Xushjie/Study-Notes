# DNS resource record

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A structured DNS data item associated with a name, type, and other fields.

## Usage and distinctions

Common types include A, AAAA, CNAME, MX, and NS; their meanings differ.

## Examples

> The DNS zone contains an A record for the host.

> Check the record type and time to live.
