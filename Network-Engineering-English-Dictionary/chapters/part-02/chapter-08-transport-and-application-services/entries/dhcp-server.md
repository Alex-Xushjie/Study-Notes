# DHCP server

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A server that supplies configuration information to DHCP clients.

## Usage and distinctions

An available server process does not guarantee that a client’s request reaches it or that an address is available.

## Examples

> The DHCP server offers an address to the client.

> Check the server’s address pool and lease records.
