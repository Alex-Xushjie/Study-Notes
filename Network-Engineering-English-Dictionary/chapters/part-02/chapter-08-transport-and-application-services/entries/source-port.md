# source port

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The transport-layer port number associated with the sender of a segment or datagram.

## Usage and distinctions

The source port is part of a transport conversation; its use depends on the protocol and application.

## Examples

> The client uses an ephemeral source port.

> Record the source IP address and source port.
