# DHCP relay

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A function that forwards DHCP messages between clients and servers on different networks.

## Usage and distinctions

DHCP relay behavior differs between DHCPv4 and DHCPv6; use the correct device documentation.

## Examples

> The router acts as a DHCP relay for the client subnet.

> Verify the relay configuration and server reachability.
