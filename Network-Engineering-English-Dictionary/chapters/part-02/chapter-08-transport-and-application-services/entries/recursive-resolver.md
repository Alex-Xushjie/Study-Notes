# recursive resolver

**Network engineering term** · Chapter 08

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A DNS resolver that obtains an answer on behalf of a client, using cache and other DNS servers as needed.

## Usage and distinctions

A recursive resolver and an authoritative name server have distinct roles, although software can support both.

## Examples

> The client sends the query to its recursive resolver.

> Check whether the resolver has a cached answer.
