# IGMP membership report

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IGMP message by which a host communicates multicast membership information.

## Usage and distinctions

Report contents differ by IGMP version; IGMPv3 can convey source-filter information.

## Examples

> The host sends an IGMP membership report.

> Verify the group and interface in the report.
