# IGMP leave message

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IGMPv2 message indicating that a host is leaving a multicast group.

## Usage and distinctions

IGMP version behavior differs; a leave from one host does not prove no other hosts remain.

## Examples

> The receiver sends an IGMP leave message.

> Check whether another receiver remains on the segment.
