# Spanning Tree Protocol

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A family of bridge protocols that prevents forwarding loops by establishing a loop-free active topology.

## Usage and distinctions

Abbreviation: STP. Different variants have different behavior and convergence characteristics.

## Examples

> Spanning Tree Protocol blocks a redundant Layer 2 path.

> Check the spanning-tree state before moving the link.
