# MAC address

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A data-link address used by Ethernet interfaces and frames.

## Usage and distinctions

MAC addresses identify link-layer endpoints or groups in a local context; they are not IP addresses.

## Examples

> The frame contains a destination MAC address.

> Check the switch’s MAC address table.
