# Layer 2 loop

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A Layer 2 topology condition in which frames can circulate repeatedly.

## Usage and distinctions

Loops can arise when redundant Layer 2 paths forward simultaneously without an effective loop-prevention mechanism.

## Examples

> A Layer 2 loop caused a broadcast storm.

> Check the spanning-tree topology before connecting the redundant cable.
