# IGMP INCLUDE mode

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A source-filter mode indicating interest in traffic from the listed sources for a group.

## Usage and distinctions

INCLUDE semantics must be interpreted with the group and complete source list.

## Examples

> The host reports INCLUDE mode for the source.

> Verify that the intended source appears in the list.
