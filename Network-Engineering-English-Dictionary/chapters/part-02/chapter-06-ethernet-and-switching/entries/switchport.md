# switchport

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A switch interface operating with Layer 2 switching functions.

## Usage and distinctions

Switchport terminology is vendor-dependent; some platforms allow a physical interface to operate as a routed port instead.

## Examples

> The switchport is configured as an access port.

> Verify the switchport mode and VLAN assignment.
