# VLAN tag

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Information inserted into an Ethernet frame to identify VLAN membership.

## Usage and distinctions

IEEE 802.1Q tagging changes the frame format; capture hardware or drivers can sometimes remove tags from observed packets.

## Examples

> The trunk transmits the frame with an 802.1Q VLAN tag.

> Inspect the tag in the capture.
