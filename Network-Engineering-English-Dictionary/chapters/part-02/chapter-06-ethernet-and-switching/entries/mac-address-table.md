# MAC address table

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A switch table associating learned MAC addresses with forwarding interfaces and bridge domains or VLANs.

## Usage and distinctions

Entries may be learned dynamically or configured; aging and display behavior vary by platform.

## Examples

> The MAC address table shows the host on port 12.

> Check the address table in the correct VLAN.
