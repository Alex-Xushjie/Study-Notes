# broadcast domain

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A set of interfaces over which a Layer 2 broadcast can be forwarded.

## Usage and distinctions

The effective scope depends on VLANs, bridging, and design.

## Examples

> The VLAN defines a separate broadcast domain.

> A router separates the two Layer 2 broadcast domains.
