# IGMP source filter

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A membership condition specifying which multicast sources are included or excluded for a group.

## Usage and distinctions

INCLUDE and EXCLUDE have distinct meanings; interpret them with the complete report state.

## Examples

> The IGMPv3 report includes a source filter.

> Check the group, filter mode, and source list.
