# multicast receiver

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A host or application that requests or receives traffic for a multicast group.

## Usage and distinctions

Application membership, host state, and network forwarding are related but distinct.
