# multicast MAC address

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A Layer 2 address identifying an Ethernet multicast group.

## Usage and distinctions

Multiple IPv4 multicast groups can map to the same Ethernet multicast MAC address.

## Examples

> The Ethernet frame uses a multicast MAC address.

> Compare the multicast MAC with the IP group address.
