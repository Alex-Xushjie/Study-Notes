# MAC learning

**Network engineering term** · Chapter 06

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process by which a bridge associates a source MAC address with an ingress interface.

## Usage and distinctions

Learning typically uses the source MAC address and forwarding context, not the destination address.

## Examples

> The switch learns the host’s MAC address on the access port.

> Generate traffic from the host and check the learned entry.
