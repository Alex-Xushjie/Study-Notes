# IP address conflict

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A condition in which the same IP address is assigned to multiple endpoints in a context where it must be unique.

## Usage and distinctions

An identical address may be valid in separate isolated networks; the relevant addressing context matters.

## Examples

> The duplicate address caused an IP address conflict.

> Check the address inventory before assigning the host address.
