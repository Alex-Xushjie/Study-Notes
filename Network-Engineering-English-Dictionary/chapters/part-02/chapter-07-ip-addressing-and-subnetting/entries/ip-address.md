# IP address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network-layer address used to identify an interface or endpoint for IP communication.

## Usage and distinctions

IPv4 and IPv6 use different address formats and sizes. Addresses may be assigned to interfaces rather than physical devices as a whole.

## Examples

> The server has an IP address in the management subnet.

> Verify the source and destination IP addresses.
