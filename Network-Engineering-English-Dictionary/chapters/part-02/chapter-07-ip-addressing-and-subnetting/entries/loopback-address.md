# loopback address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An address used by a host to refer to itself.

## Usage and distinctions

A protocol loopback address is different from a vendor-specific logical loopback interface, which may have other addresses.

## Examples

> The IPv4 loopback address 127.0.0.1 refers to the local host.

> The IPv6 loopback address is ::1.
