# IPv6 global unicast address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IPv6 unicast address with global scope.

## Usage and distinctions

Global scope does not by itself guarantee that an address is reachable from the public Internet.

## Examples

> The interface has an IPv6 global unicast address.

> Check the prefix and routing policy for the assigned address.
