# IP address management

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The practice and tools used to plan, track, and administer IP address space.

## Usage and distinctions

Abbreviation: IPAM. An IPAM record should be reconciled with the actual network state.

## Examples

> Update the IP address management system after the assignment.

> Check the IPAM record for the allocated subnet.
