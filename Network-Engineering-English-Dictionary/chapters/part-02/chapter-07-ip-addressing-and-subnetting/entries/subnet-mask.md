# subnet mask

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A 32-bit mask used to identify the network portion of an IPv4 address.

## Usage and distinctions

Subnet mask is commonly expressed in dotted decimal for IPv4; IPv6 uses prefix lengths rather than dotted-decimal masks.

## Examples

> The subnet mask is 255.255.255.0.

> The mask 255.255.255.0 corresponds to /24.
