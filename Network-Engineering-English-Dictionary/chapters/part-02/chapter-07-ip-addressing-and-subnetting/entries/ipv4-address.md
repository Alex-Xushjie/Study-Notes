# IPv4 address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A 32-bit address used by Internet Protocol version 4.

## Usage and distinctions

IPv4 addresses are commonly written as four decimal octets. The documentation block 192.0.2.0/24 is reserved for examples.

## Examples

> The server address is 192.0.2.10.

> Record the IPv4 address and prefix length.
