# Classless Inter-Domain Routing

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An addressing and routing approach that uses variable-length prefixes instead of fixed class boundaries.

## Usage and distinctions

Abbreviation: CIDR. The notation combines an address with a prefix length.

## Examples

> The route is written in CIDR notation as 192.0.2.0/24.

> The provider allocated an address block using CIDR.
