# network prefix

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The leading bits that identify a network or a group of addresses.

## Usage and distinctions

A prefix identifies an address range; a route also contains forwarding information such as the next hop.

## Examples

> The route covers the 192.0.2.0/24 network prefix.

> Verify the prefix length before adding the route.
