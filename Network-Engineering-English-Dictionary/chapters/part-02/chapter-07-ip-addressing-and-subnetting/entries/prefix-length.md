# prefix length

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The number of leading address bits used to identify a network prefix.

## Usage and distinctions

Prefix length is written with a slash, such as /24 or /64. It applies to both IPv4 and IPv6.

## Examples

> The IPv4 address has a prefix length of 24.

> The IPv6 network uses a /64 prefix.
