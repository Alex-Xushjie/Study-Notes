# private IPv4 address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IPv4 address from ranges reserved for private internetworks.

## Usage and distinctions

RFC 1918 specifies 10/8, 172.16/12, and 192.168/16. Private addressing alone is not a security control.

## Examples

> The branch uses private IPv4 addresses internally.

> Check whether address translation is used at the edge.
