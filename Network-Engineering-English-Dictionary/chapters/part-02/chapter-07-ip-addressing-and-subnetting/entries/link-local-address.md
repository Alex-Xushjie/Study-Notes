# link-local address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An address intended for communication on a local network link.

## Usage and distinctions

IPv6 link-local unicast addresses use fe80::/10. Their scope is the local link, not global routing.

## Examples

> The IPv6 interface has a link-local address.

> The routing protocol uses a link-local next hop.
