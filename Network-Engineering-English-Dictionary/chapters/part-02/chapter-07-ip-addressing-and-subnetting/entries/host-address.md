# host address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IP address assigned to an interface or endpoint within a network.

## Usage and distinctions

Whether an address is assignable depends on the network and prefix context.

## Examples

> 192.0.2.10/24 is a host address in the example subnet.

> Confirm that the host address does not conflict with another assignment.
