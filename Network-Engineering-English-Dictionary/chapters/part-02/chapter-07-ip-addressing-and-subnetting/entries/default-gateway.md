# default gateway

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A next-hop router used by a host when no more specific route applies.

## Usage and distinctions

A gateway configured on the host is usually an address on the local link; static routes may provide more specific paths.

## Examples

> The host sends remote traffic to its default gateway.

> Check whether the default gateway is reachable.
