# octet

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A group of eight bits.

## Usage and distinctions

An octet has values from 0 through 255 when interpreted as an unsigned integer.

## Examples

> An IPv4 address is commonly written as four decimal octets.

> Each decimal octet represents eight bits.
