# IPv6 unique local address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IPv6 unicast address intended for local communications within a limited set of sites.

## Usage and distinctions

Unique local addresses use fc00::/7; locally assigned prefixes use the fd00::/8 portion.

## Examples

> The internal service uses a unique local address.

> Document the unique local prefix used by the site.
