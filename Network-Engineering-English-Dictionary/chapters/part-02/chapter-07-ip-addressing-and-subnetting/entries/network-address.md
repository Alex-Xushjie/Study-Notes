# IPv4 network address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The address with all host bits set to zero for an IPv4 subnet.

## Usage and distinctions

Host address assignment rules depend on the subnet type and use; special cases include /31 point-to-point links.

## Examples

> 192.0.2.0 is the network address of 192.0.2.0/24.

> Record the network address and prefix length.
