# public IP address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An IP address used in globally reachable addressing, subject to routing and policy.

## Usage and distinctions

An address being publicly assigned does not guarantee reachability; routing, filtering, and address policy also matter.

## Examples

> The service is assigned a public IP address.

> Confirm whether the public address is advertised and reachable.
