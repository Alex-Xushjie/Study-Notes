# IPv6 address

**Network engineering term** · Chapter 07

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A 128-bit address used by Internet Protocol version 6.

## Usage and distinctions

IPv6 addresses use hexadecimal groups. The 2001:db8::/32 block is reserved for documentation examples.

## Examples

> The host has the IPv6 address 2001:db8::10.

> Check the IPv6 address and prefix length.
