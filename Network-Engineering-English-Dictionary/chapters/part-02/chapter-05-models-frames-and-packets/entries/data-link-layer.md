# data link layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The layer concerned with transferring frames across a local link.

## Usage and distinctions

The OSI data link layer is Layer 2. Ethernet encompasses both Layer 1 and Layer 2 functions.

## Examples

> Ethernet operates at the data link layer and physical layer.

> The switch uses data-link information when forwarding a frame.
