# presentation layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The OSI reference layer concerned with representation and transformation of data.

## Usage and distinctions

Encoding, compression, and encryption can be implemented at different places in actual systems.

## Examples

> The presentation layer is Layer 6 in the OSI model.

> Data encoding is a presentation concern.
