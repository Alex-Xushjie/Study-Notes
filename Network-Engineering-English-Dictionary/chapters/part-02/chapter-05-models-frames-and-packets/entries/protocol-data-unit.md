# protocol data unit

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A unit of information specified by a protocol for exchange between protocol entities.

## Usage and distinctions

Abbreviation: PDU. This PDU is not a power distribution unit; use context to distinguish the abbreviation.

> A frame is an example of a link-layer protocol data unit.
