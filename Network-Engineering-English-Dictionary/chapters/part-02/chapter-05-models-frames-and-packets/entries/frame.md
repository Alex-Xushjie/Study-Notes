# frame

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A link-layer protocol data unit that carries data across a link.

## Usage and distinctions

The exact fields depend on the link-layer protocol. An Ethernet frame is not identical to the IP packet it may carry.

## Examples

> The switch forwards the Ethernet frame.

> The frame contains source and destination MAC addresses.
