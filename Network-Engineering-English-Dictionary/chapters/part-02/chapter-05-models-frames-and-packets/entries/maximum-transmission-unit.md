# maximum transmission unit

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The largest packet size a network-layer interface can transmit without fragmentation at that layer.

## Usage and distinctions

Abbreviation: MTU. Layer definitions and vendor displays vary; do not confuse IP MTU with complete Ethernet frame size.

## Examples

> The interface MTU is configured as 1500 bytes.

> Check the MTU along the path if large packets fail.
