# session layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The OSI reference layer concerned with establishing, managing, and ending communication sessions.

## Usage and distinctions

Practical protocol stacks often group functions differently from the OSI reference model.

## Examples

> The session layer is Layer 5 in the OSI model.

> The application handles session management in its own implementation.
