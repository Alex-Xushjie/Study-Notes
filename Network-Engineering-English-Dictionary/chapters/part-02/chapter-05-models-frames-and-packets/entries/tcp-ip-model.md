# TCP/IP model

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A model that groups the functions of the Internet protocol suite into layers.

## Usage and distinctions

A common four-layer view uses link, internet, transport, and application layers; another presentation separates physical and data-link layers.

## Examples

> The TCP/IP model describes communication using a smaller set of layers.

> Different teaching materials may present slightly different layer groupings.
