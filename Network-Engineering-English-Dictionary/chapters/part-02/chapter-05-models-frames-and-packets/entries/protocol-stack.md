# protocol stack

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A collection of protocols organized into cooperating layers.

## Usage and distinctions

The stack is an implementation or organized collection of protocols; layer boundaries are models and can differ between frameworks.

## Examples

> The packet passes through the host’s protocol stack.

> The protocol stack adds information at multiple layers.
