# encapsulation

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process of placing data inside a protocol unit and adding information needed by that protocol.

## Usage and distinctions

Encapsulation is not encryption. Added headers and trailers depend on the protocols in use.

## Examples

> The host encapsulates the IP packet in an Ethernet frame.

> Each layer adds its own protocol information.
