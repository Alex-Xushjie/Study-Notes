# TCP segment

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A TCP protocol data unit containing a TCP header and, optionally, data.

## Usage and distinctions

Segment is standard TCP terminology; UDP commonly uses datagram.
