# protocol header

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Protocol control information placed before the associated data.

## Usage and distinctions

Header fields depend on the protocol and version. Avoid assuming all headers have the same length.

## Examples

> The IP header contains source and destination addresses.

> Examine the TCP header for the destination port.
