# OSI model

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A seven-layer reference model for describing network communication functions.

## Usage and distinctions

The OSI model is a conceptual reference, not a literal description of every implementation.

## Examples

> The OSI model separates network functions into seven layers.

> The team used the OSI model to organize the troubleshooting discussion.
