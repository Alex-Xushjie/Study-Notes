# transport layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The layer that provides communication functions between application endpoints.

## Usage and distinctions

The OSI transport layer is Layer 4. TCP and UDP offer different reliability and connection properties.

## Examples

> TCP and UDP provide different transport-layer services.

> Check the transport-layer port used by the application.
