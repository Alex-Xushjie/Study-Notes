# network layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The layer concerned with delivering packets across interconnected networks.

## Usage and distinctions

The OSI network layer is Layer 3. IP forwarding does not guarantee end-to-end delivery.

## Examples

> IP is commonly described as a network-layer protocol.

> The router examines network-layer information.
