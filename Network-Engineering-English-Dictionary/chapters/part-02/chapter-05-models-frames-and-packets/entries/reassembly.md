# IP reassembly

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The reconstruction of an original IP packet from its fragments.

## Usage and distinctions

Reassembly behavior and timers depend on the IP version and implementation.

## Examples

> The destination host reassembles the IP fragments.

> Missing fragments can prevent successful reassembly.
