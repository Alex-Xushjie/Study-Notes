# payload

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The data carried within a protocol unit, excluding that unit’s own protocol control information.

## Usage and distinctions

Payload is relative to a particular protocol layer: a TCP segment can be an IP payload while containing its own header.

## Examples

> The IP packet carries a TCP segment as its payload.

> The frame payload includes the network-layer packet.
