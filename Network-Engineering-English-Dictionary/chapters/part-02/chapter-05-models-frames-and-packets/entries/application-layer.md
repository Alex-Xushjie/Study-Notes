# application layer

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The layer that provides network services used by applications.

## Usage and distinctions

The application layer is Layer 7 in the OSI model; the term also has meanings in other models.

## Examples

> DNS is commonly discussed as an application-layer protocol.

> The application-layer request failed even though the TCP connection was established.
