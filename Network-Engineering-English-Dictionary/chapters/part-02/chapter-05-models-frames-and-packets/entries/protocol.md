# network protocol

**Network engineering term** · Chapter 05

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A set of rules governing communication between network participants.

## Usage and distinctions

Protocols specify formats and behavior; a protocol is not the same thing as an individual packet.

## Examples

> The protocol defines how the devices exchange messages.

> Both endpoints must support compatible protocol behavior.
