# IPsec security association

**Network engineering term** · Chapter 12

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A set of parameters defining how IPsec protects traffic in one direction.

## Usage and distinctions

Abbreviation: SA. An active SA does not alone guarantee that the intended application traffic matches the policy.

## Examples

> The IPsec security association is active.

> Check the selectors and counters on both endpoints.
