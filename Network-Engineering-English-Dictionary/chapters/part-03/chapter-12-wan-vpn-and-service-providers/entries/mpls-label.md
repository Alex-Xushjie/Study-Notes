# MPLS label

**Network engineering term** · Chapter 12

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A short identifier used by an MPLS forwarding device to select forwarding treatment.

## Usage and distinctions

Labels have local significance in a forwarding context; a label is not an IP address.

## Examples

> The router forwards the packet using the MPLS label.

> Check the incoming label and forwarding action.
