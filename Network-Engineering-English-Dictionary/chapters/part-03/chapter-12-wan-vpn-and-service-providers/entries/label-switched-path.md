# label-switched path

**Network engineering term** · Chapter 12

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A path through an MPLS network along which packets are forwarded using label operations.

## Usage and distinctions

Abbreviation: LSP. In IS-IS, LSP can instead mean link-state PDU.

## Examples

> The provider established a label-switched path through its backbone.

> Check the path and associated label forwarding state.
