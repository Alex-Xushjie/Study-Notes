## Key terms

| Word | Meaning |
| --- | --- |
| [network underlay](entries/underlay.md) | The network providing transport for an overlay. |
| [network tunnel](entries/tunnel.md) | A logical path carrying one packet type within another. |
| [tunnel endpoint](entries/tunnel-endpoint.md) | A device or address at one end of a tunnel. |
| [virtual private network](entries/virtual-private-network.md) | A logical private network built over shared infrastructure. |

## Examples and usage

> Check underlay connectivity before troubleshooting the overlay.

> Confirm that the remote tunnel endpoint is reachable.

> The site-to-site VPN connects the branch and headquarters.

> A tunnel being up does not guarantee application connectivity.
