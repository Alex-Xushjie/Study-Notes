# OSPF router ID

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A 32-bit identifier used to identify a router in OSPF.

## Usage and distinctions

The router ID is written in dotted-decimal form but is an identifier; it is not necessarily a reachable interface address.

## Examples

> Each OSPF router must use an appropriate router ID.

> Check for duplicate router IDs.
