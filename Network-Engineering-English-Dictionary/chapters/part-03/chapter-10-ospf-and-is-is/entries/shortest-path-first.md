# shortest path first

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A calculation that derives least-cost paths through a topology graph.

## Usage and distinctions

Abbreviation: SPF. Path cost depends on the protocol’s metrics and applicable rules.

## Examples

> The router runs shortest path first after the topology changes.

> Frequent topology changes can trigger repeated SPF calculations.
