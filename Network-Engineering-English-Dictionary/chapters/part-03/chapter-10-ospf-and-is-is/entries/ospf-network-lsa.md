# OSPF network LSA

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An OSPF link-state advertisement describing a transit multiaccess network and its attached routers.

## Usage and distinctions

In OSPFv2, the designated router originates this advertisement for the network.

## Examples

> The designated router originates the network LSA.

> Check whether a network LSA exists for the transit segment.
