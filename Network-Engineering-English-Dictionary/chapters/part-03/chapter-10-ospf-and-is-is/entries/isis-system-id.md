# IS-IS system ID

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The portion of an IS-IS network entity title used to identify a system within the routing domain.

## Usage and distinctions

The system ID is distinct from an IPv4 or IPv6 interface address.

## Examples

> Assign a unique IS-IS system ID to the router.

> Investigate duplicate system IDs before enabling the new node.
