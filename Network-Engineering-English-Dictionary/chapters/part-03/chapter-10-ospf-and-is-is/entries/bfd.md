# Bidirectional Forwarding Detection

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A protocol that provides rapid detection of failures on a forwarding path between systems.

## Usage and distinctions

Abbreviation: BFD. It detects path failure but does not itself replace the routing protocol.

## Examples

> The OSPF session uses BFD for failure detection.

> Check the BFD state and negotiated timers.
