# OSPF ExStart state

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A neighbor state in which routers negotiate how to begin exchanging database descriptions.

## Usage and distinctions

An MTU mismatch is one possible cause; use protocol traces and platform diagnostics to confirm.
