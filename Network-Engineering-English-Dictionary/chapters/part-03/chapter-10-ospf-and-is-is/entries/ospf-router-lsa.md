# OSPF router LSA

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An OSPF link-state advertisement describing a router and its links within an area.

## Usage and distinctions

This description refers to OSPFv2 terminology; OSPFv3 uses a related but distinct format.

## Examples

> Inspect the router LSA for the missing link.

> Each router originates a router LSA for each area to which it belongs.
