# Open Shortest Path First

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A link-state interior gateway protocol used to distribute routing information within an autonomous system.

## Usage and distinctions

Abbreviation: OSPF. OSPFv2 and OSPFv3 are distinct protocol versions with different specifications.

## Examples

> The routers exchange routes using OSPF.

> Check the OSPF neighbor state on both ends.
