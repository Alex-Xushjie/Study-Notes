# OSPF Exchange state

**Network engineering term** · Chapter 10

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A neighbor state in which database description packets are exchanged.

## Usage and distinctions

The routers describe their link-state databases before requesting missing or newer information.

## Examples

> The neighbors entered the OSPF Exchange state.

> Check for repeated database description packets during Exchange.
