# routing table

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A collection of routing information used to select paths to destination prefixes.

## Usage and distinctions

A routing table and a hardware forwarding table are related but may be represented differently by the platform.

## Examples

> The routing table contains a route to the remote subnet.

> Check the routing table on the affected router.
