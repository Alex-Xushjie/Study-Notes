# PIM sparse mode

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A PIM mode in which multicast distribution state is built through explicit signaling.

## Usage and distinctions

Abbreviation: PIM-SM. Its behavior depends on the group mode and protocol configuration.
