# reverse path forwarding

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A multicast forwarding check that uses the expected path toward a source or tree root.

## Usage and distinctions

Abbreviation: RPF. The precise lookup and expected neighbor depend on multicast state and implementation.

## Examples

> The multicast packet fails the reverse-path-forwarding check.

> Verify the RPF interface and upstream routing information.
