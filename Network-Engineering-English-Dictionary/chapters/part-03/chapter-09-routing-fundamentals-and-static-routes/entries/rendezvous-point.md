# PIM rendezvous point

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A router used as a reference point for certain PIM sparse-mode shared-tree functions.

## Usage and distinctions

Abbreviation: RP. Source-specific multicast does not use an RP for ordinary SSM operation.

## Examples

> The group maps to a rendezvous point.

> Verify the rendezvous-point address and reachability.
