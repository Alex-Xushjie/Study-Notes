# any-source multicast

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A multicast service model in which receivers join a group without specifying a single source.

## Usage and distinctions

Abbreviation: ASM. The forwarding and source-discovery mechanisms depend on the protocol design.
