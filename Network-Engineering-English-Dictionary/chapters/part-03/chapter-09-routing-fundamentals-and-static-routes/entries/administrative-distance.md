# administrative distance

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A vendor-specific preference value used to compare route sources for the same prefix.

## Usage and distinctions

Terminology and default values vary by vendor; some platforms use the term preference instead.

## Examples

> The static route has a lower administrative distance than the learned route on this platform.

> Check the route preference used by the device.
