# return path

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The path used for traffic traveling back from a destination to the original source.

## Usage and distinctions

Reachability can fail in one direction even if the forward route exists.

## Examples

> Check the return path from the server to the client.

> The forward and return paths may use different routers.
