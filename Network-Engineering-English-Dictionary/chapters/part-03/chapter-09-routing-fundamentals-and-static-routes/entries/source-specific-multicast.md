# source-specific multicast

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A multicast service model in which receivers request traffic from specified sources for a group.

## Usage and distinctions

Abbreviation: SSM. The deployment must support the appropriate host membership and routing mechanisms.

## Examples

> The receiver joins the source-specific multicast channel.

> Verify the source and group requested by the receiver.
