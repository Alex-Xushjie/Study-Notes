# outgoing interface

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The interface selected to transmit a packet toward its next hop or destination.

## Usage and distinctions

An outgoing interface and a next-hop address describe related but different forwarding information.

## Examples

> The route uses the outgoing interface toward the provider.

> Check the status of the outgoing interface.
