# route metric

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A value used by a routing protocol or implementation to compare candidate routes.

## Usage and distinctions

Metrics are protocol-specific; values from different protocols are not necessarily directly comparable.

## Examples

> OSPF uses cost as its route metric.

> Check the metric of each candidate path.
