# routing loop

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A condition in which packets are forwarded repeatedly through a cycle of routers.

## Usage and distinctions

IP hop limits can prevent indefinite circulation, but they do not remove the underlying loop.

## Examples

> The traceroute suggests a routing loop.

> Check the next-hop decisions at each router.
