# static route

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A route configured explicitly rather than learned dynamically by a routing protocol.

## Usage and distinctions

A static route can depend on interface or next-hop reachability and may be removed or marked inactive according to platform behavior.

## Examples

> The administrator configured a static route to the branch network.

> Confirm the next hop before installing the static route.
