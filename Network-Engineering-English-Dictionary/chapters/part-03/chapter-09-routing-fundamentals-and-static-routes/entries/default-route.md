# default route

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A route used when no more specific route matches a destination address.

## Usage and distinctions

IPv4 default route is 0.0.0.0/0; IPv6 default route is ::/0.

## Examples

> The router sends unmatched traffic to the default route.

> Check the next hop for 0.0.0.0/0.
