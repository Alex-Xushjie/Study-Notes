# multicast outgoing interface list

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The set of interfaces on which matching multicast traffic is eligible to be forwarded.

## Usage and distinctions

Abbreviated OIL on some platforms; interface state and filtering affect actual forwarding.
