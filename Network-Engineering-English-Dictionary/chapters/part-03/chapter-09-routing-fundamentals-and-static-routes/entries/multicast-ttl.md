# multicast IP time to live

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The IPv4 TTL field value carried by a multicast packet.

## Usage and distinctions

Routers decrement IPv4 TTL during forwarding; actual boundary rules depend on configuration.

## Examples

> The multicast packet arrives with a low TTL.

> Check whether the configured TTL scope affects the path.
