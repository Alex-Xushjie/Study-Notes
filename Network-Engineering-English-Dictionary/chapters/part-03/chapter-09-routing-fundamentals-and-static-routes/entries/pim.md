# Protocol Independent Multicast

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A family of multicast routing protocols that uses underlying unicast routing information to support multicast forwarding.

## Usage and distinctions

Abbreviation: PIM. Different PIM modes have different forwarding and control-plane behavior.

## Examples

> The routers run PIM on the multicast path.

> Check PIM neighbors and multicast routing state.
