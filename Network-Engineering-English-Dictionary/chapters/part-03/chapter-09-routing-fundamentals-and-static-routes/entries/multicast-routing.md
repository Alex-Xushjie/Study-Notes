# IP multicast routing

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The forwarding of IP multicast traffic across routed networks.

## Usage and distinctions

Multicast routing uses group and possibly source information; it differs from ordinary unicast forwarding.

## Examples

> The network uses multicast routing between the source and receivers.

> Check multicast routing state on the path.
