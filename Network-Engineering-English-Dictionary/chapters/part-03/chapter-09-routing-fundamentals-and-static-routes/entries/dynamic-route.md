# dynamic route

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A route learned through a dynamic routing protocol.

## Usage and distinctions

Dynamic routing does not remove the need to validate policy, convergence, and reachability.

## Examples

> The router learns the prefix as a dynamic route.

> Check the routing protocol neighbor if the route disappears.
