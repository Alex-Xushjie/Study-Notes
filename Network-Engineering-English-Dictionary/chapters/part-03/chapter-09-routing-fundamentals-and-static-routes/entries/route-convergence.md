# routing convergence

**Network engineering term** · Chapter 09

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The process by which routers reach a consistent view of routing after a change.

## Usage and distinctions

Convergence time depends on failure detection, protocol behavior, topology, and forwarding updates.

## Examples

> The network converges after the link failure.
