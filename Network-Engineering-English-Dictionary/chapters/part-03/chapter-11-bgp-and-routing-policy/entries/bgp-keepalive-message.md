# BGP KEEPALIVE message

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A BGP message exchanged to help maintain a BGP session.

## Usage and distinctions

The negotiated hold time affects session liveness; a live session does not prove that routes are accepted.

## Examples

> The peers exchange BGP KEEPALIVE messages.

> Investigate packet loss if keepalives stop arriving.
