# autonomous system

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A collection of IP networks and routers under a common routing administration that presents a routing policy to other networks.

## Usage and distinctions

Abbreviation: AS. An autonomous system is a routing administration concept, not necessarily a single physical network.

## Examples

> The provider assigns an autonomous system number to the customer.

> Check the autonomous system number on both BGP peers.
