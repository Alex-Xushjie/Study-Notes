# BGP prefix

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network address and prefix length carried as reachability information in BGP.

## Usage and distinctions

A prefix represents an address range. Receipt, acceptance, selection, and advertisement are separate stages.

## Examples

> The provider advertises the expected prefix.

> Check whether the prefix is received and accepted.
