# BGP ORIGIN attribute

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A BGP path attribute indicating the origin category associated with the advertised routing information.

## Usage and distinctions

The ORIGIN attribute is not a proof of route authorization or a substitute for RPKI validation.

## Examples

> Inspect the BGP ORIGIN attribute in the received route.

> The route carries an incomplete origin code.
