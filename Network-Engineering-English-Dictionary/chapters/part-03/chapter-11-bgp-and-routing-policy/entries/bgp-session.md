# BGP session

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A connection between BGP peers used to exchange BGP messages.

## Usage and distinctions

A BGP session normally uses TCP port 179. Established session state alone does not prove routes or application traffic are working.
