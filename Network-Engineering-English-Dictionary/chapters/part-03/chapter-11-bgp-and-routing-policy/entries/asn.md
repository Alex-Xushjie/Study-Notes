# autonomous system number

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A number used to identify an autonomous system in routing.

## Usage and distinctions

Abbreviation: ASN. Private and public ASN ranges have different intended uses; check the current allocations and policy.

## Examples

> The BGP session uses the expected autonomous system number.

> Verify whether the peer uses a two-octet or four-octet ASN representation.
