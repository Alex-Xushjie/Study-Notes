# BGP OPEN message

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A BGP message used to initiate a session and exchange session parameters.

## Usage and distinctions

Parameter and capability negotiation can affect which address families the peers exchange.

## Examples

> The router sends a BGP OPEN message after the TCP connection is established.

> Inspect the OPEN message for the peer’s advertised capabilities.
