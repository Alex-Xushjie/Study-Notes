# BGP import policy

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Rules applied to routes received from a BGP peer.

## Usage and distinctions

Also called inbound policy. Actual processing stages and terminology vary by platform.

## Examples

> The import policy accepts only the expected prefixes.

> Check the import policy if the prefix is received but not installed.
