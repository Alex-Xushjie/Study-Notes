# prefix filter

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A rule that matches network prefixes according to specified criteria.

## Usage and distinctions

A filter can include range conditions; matching the base prefix is not the same as accepting every more-specific prefix.

## Examples

> The prefix filter permits only the customer’s allocated block.

> Verify the permitted prefix lengths in the filter.
