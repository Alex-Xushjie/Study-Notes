# BGP cluster ID

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An identifier used in route reflection to help prevent routing loops among reflectors.

## Usage and distinctions

The cluster ID is used with route-reflection loop prevention; design choices affect redundancy and visibility.

## Examples

> Configure a shared BGP cluster ID on redundant reflectors in the same cluster.

> Inspect the cluster list when a reflected route is rejected.
