# AS_PATH

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A BGP path attribute containing a sequence of autonomous-system path segments.

## Usage and distinctions

AS_PATH participates in loop prevention and path selection, but the complete selection process is more complex than simply choosing the fewest AS numbers.

## Examples

> The AS_PATH contains the provider’s autonomous system number.

> Check the AS_PATH for unexpected entries.
