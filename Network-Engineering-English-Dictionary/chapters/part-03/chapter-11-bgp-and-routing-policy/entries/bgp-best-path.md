# BGP best path

**Network engineering term** · Chapter 11

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The path selected by the BGP decision process among eligible candidates.

## Usage and distinctions

Selection algorithms have ordered steps and platform-specific options. Multipath may install more than one eligible path when configured.

> The router selects one BGP path as best.
