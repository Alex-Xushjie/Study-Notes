## Quick review

1. Is site access the same as change approval?
2. What should be checked besides the number of available rack units?
3. What is the difference between a serial number and an asset tag?
4. What does an as-built drawing show?

**Answers:** 1. No. 2. Depth, weight, power, airflow, and service clearance. 3. A serial number identifies the manufacturer's unit; an asset tag tracks organizational inventory. 4. The completed installation.
