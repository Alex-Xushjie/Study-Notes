# rack screw

**Network engineering term** · Chapter 04

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A screw used to secure a device or accessory to a rack.

## Usage and distinctions

Screw thread type and size must match the rack or mounting hardware.

## Examples

> Use the supplied rack screws to secure the mounting brackets.

> Check that each rack screw is tightened as specified.
