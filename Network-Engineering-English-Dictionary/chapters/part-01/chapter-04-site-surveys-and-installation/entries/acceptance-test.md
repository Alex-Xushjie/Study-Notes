# acceptance test

**Network engineering term** · Chapter 04

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A planned test used to determine whether a deliverable meets agreed acceptance criteria.

## Usage and distinctions

The test scope and pass criteria should be agreed in advance; a successful test only supports the conditions it covers.

## Examples

> Run the acceptance test after installation.

> Document the acceptance test results.
