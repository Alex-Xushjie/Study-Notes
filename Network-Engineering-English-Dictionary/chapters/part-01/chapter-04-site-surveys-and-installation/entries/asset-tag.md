# asset tag

**Network engineering term** · Chapter 04

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A label or identifier used to track an item as an organizational asset.

## Usage and distinctions

An asset tag identifies an inventory item; it is not necessarily the manufacturer’s serial number.

## Examples

> Record the asset tag in the installation checklist.

> The asset tag does not match the inventory record.
