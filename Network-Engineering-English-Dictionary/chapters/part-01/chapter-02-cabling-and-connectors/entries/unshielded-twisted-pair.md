# unshielded twisted pair

**Network engineering term** · Chapter 02

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A twisted-pair cable that does not have an overall metallic shield.

## Usage and distinctions

Abbreviation: UTP. Cable design varies; an unshielded cable still has insulated conductors.

## Examples

> The installation uses unshielded twisted-pair cable.

> Check the cable category before selecting the link speed.
