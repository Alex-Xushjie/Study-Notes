# stranded conductor

**Network engineering term** · Chapter 02

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A conductor formed from multiple smaller wires.

## Usage and distinctions

Stranding can improve flexibility; connector compatibility must still be verified.

## Examples

> The flexible patch cord uses stranded conductors.

> Check the cable construction before selecting a plug.
