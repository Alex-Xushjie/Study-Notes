# Ethernet cable

**Network engineering term** · Chapter 02

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A cable assembly or cable used to carry Ethernet signals between network interfaces.

## Usage and distinctions

Ethernet can run over different media, including copper and fiber. In everyday speech Ethernet cable often means a copper patch cord.

## Examples

> Use an Ethernet cable to connect the access point.

> Verify that the cable and interfaces support the intended Ethernet application.
