# network switch

**Countable noun** · Chapter 01 · `physical`

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

[See this term in the 02 rack visual spread](../02-rack.md).

## Definition

A network device that connects ports and forwards traffic between network connections.

## Usage and distinctions

Countable noun. An Ethernet switch commonly forwards frames using MAC address information; capabilities vary by model.

## Common combinations

access switch; switch port; rack-mounted switch

## Examples

> The access switch is mounted in rack R02.

> The patch panel connects to the switch through patch cords.
