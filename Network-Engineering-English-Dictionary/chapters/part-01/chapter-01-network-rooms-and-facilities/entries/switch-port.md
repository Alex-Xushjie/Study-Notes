# switch port

**Countable noun** · Chapter 01 · `physical`

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

[See this term in the 02 rack visual spread](../02-rack.md).

## Definition

A physical interface on a network switch used to connect a cable or transceiver.

## Usage and distinctions

Countable noun. A port has an identifier; the connector type and speed depend on the hardware and configuration.

## Common combinations

access port; switch port number; port label

## Examples

> The patch cord is connected to switch port 12.

> Check the port label before tracing the cable.
