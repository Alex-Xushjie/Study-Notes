# patch panel

**Countable noun.** · Chapter 01 · `physical`

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

![Illustrated detail: patch panel.](../../../../assets/visual-patch-panel.svg)

*An organized set of cable connection points. This is an illustrative detail; actual equipment varies.*

## Definition

A passive assembly that presents cable terminations as organized connection points for patch cords.

## Usage and distinctions

A patch panel presents organized cable termination points. It is passive and does not switch Ethernet frames.

## Common combinations

a fiber patch panel; patch-panel port; label the patch panel

## Examples

> Connect switch port Gi1/0/12 to port 24 on patch panel PP-02.

> The patch-panel label does not match the cable schedule.
