# link LED

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An indicator associated with the link condition of an interface.

## Usage and distinctions

Some devices combine link and activity indicators. Consult the model documentation for color and blink meanings.

## Examples

> The link LED is off on the affected port.

> Compare the link LED with the interface status.
