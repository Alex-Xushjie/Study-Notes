# administratively up

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Describing an interface that is enabled by administrative configuration.

## Usage and distinctions

An enabled interface may still lack an operational link or correct configuration.

## Examples

> The interface is administratively up.

> Check whether the physical link is also up.
