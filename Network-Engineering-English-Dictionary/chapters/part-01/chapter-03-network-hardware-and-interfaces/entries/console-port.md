# console port

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A management interface used to access a device’s console.

## Usage and distinctions

Console connections are used for management; connector type and serial settings vary by device.

## Examples

> Connect to the console port for initial setup.

> Check the console settings and cable type.
