# loopback interface

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logical interface used as a stable endpoint or local interface in many systems.

## Usage and distinctions

A logical loopback interface is distinct from the reserved host loopback address range.

## Examples

> The routing protocol uses the loopback interface address.

> Check whether the loopback address is advertised.
