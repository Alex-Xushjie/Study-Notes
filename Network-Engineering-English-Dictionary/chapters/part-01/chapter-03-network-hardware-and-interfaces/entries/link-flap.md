# link flap

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Repeated transitions of a network link between operational states.

## Usage and distinctions

A link flap is a symptom; investigate physical, device, and configuration causes.

## Common combinations

interface is flapping; link went down; link came back up; repeated link-state changes; check logs for the same time window

## Examples

> The uplink experienced several link flaps.

> Correlate the link transitions with the incident timeline.
