# VLAN interface

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logical Layer 3 interface associated with a VLAN or bridge domain on a supported platform.

## Usage and distinctions

Names and operational-state rules differ among vendors and designs.
