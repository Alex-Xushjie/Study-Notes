# routed port

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network interface configured to operate as a Layer 3 interface rather than a Layer 2 switchport.

## Usage and distinctions

Whether a port supports routed mode depends on the device and software.

## Examples

> The uplink is configured as a routed port.

> Verify the IP address and routing configuration on the port.
