# interface speed

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The configured or negotiated rate at which an interface operates.

## Usage and distinctions

Distinguish the configured setting from the negotiated operating speed; supported speeds depend on the interface and medium.

## Examples

> The interface speed is one gigabit per second.

> Check the operational speed at both ends.
