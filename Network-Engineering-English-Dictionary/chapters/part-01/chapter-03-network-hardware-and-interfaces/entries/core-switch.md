# core switch

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A switch operating in the core of a network design.

## Usage and distinctions

Core is an architectural role. The device may also perform Layer 3 routing, depending on its capabilities and configuration.

## Examples

> The core switch connects the distribution blocks.
