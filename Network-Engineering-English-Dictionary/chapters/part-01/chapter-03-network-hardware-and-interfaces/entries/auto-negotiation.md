# auto-negotiation

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An Ethernet mechanism that allows link partners to exchange supported capabilities and select an operating mode.

## Usage and distinctions

Auto-negotiation behavior depends on the physical interface and standard; do not assume manual settings are interchangeable on every link.

> The interfaces use auto-negotiation.
