# duplex mismatch

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A condition in which link partners operate with incompatible duplex settings.

## Usage and distinctions

Duplex behavior depends on interface standards and configuration; diagnose using platform evidence.

## Examples

> The legacy link shows signs of a duplex mismatch.

> Verify the actual speed and duplex settings on both devices.
