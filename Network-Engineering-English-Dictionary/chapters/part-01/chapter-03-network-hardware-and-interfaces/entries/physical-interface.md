# physical interface

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A hardware interface that connects a device to a network medium.

## Usage and distinctions

A physical interface can host logical subinterfaces or other virtual constructs.

## Examples

> The physical interface is connected to the patch panel.

> Check the port and cable at both ends.
