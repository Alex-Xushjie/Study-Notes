# interface operational state

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The reported runtime state of an interface.

## Usage and distinctions

Operational state is distinct from administrative configuration.
