# transceiver module

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A component that transmits and receives signals for a network interface.

## Usage and distinctions

Transceivers can use different media and form factors; the optical transceiver is one specific type.

## Examples

> The transceiver module is installed in the uplink port.

> Verify the module type and device compatibility.
