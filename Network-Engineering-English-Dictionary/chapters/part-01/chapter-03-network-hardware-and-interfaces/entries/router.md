# router

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network device that forwards packets between networks according to its routing information.

## Usage and distinctions

A router commonly forwards IP packets; its functions and interfaces depend on the model.

## Examples

> The router forwards the packet to the next hop.

> Check the router’s routing table before changing the configuration.
