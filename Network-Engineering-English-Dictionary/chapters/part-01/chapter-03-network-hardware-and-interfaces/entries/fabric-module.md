# fabric module

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A replaceable component providing part of a modular device’s internal switching fabric.

## Usage and distinctions

Not every chassis has separate removable fabric modules.

## Examples

> The fabric module reports a hardware alarm.

> Verify the supported replacement procedure.
