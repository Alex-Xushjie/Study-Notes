# interface counter

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A recorded quantity associated with activity or errors on a network interface.

## Usage and distinctions

Interpret counter names and reset behavior using the device documentation, and compare changes over time.

## Examples

> The input error counter increased during the test.

> Record the counters and their timestamps before troubleshooting.
