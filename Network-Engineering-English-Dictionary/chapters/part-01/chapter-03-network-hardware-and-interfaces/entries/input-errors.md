# interface input errors

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A platform-defined counter or category for receive-side interface problems.

## Usage and distinctions

Counter definitions and causes are vendor-specific; an increasing counter is not a root cause by itself.

## Examples

> The input error counter increased during the test.

> Record the counter and timestamp at both ends.
