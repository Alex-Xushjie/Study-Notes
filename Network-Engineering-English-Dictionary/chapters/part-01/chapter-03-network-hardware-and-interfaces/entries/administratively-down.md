# administratively down

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A state in which an interface is disabled by configuration or an administrative action.

## Usage and distinctions

Administrative state and physical link state are different. An enabled interface can still have no physical link.

## Examples

> The interface is administratively down.

> Confirm that the port should be enabled before changing its state.
