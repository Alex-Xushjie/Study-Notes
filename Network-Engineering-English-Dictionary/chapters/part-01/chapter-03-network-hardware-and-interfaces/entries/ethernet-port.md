# Ethernet port

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A physical interface used to connect an Ethernet medium to a device.

## Usage and distinctions

Ethernet ports can use copper or optical media. A port’s connector alone does not specify all of its capabilities.

## Examples

> Connect the patch cord to an available Ethernet port.

> Check the port type and supported speed.
