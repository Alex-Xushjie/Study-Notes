# hot-swappable

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

Describing a component that can be replaced while the system remains powered, when supported by the equipment.

## Usage and distinctions

Hot-swappable does not guarantee that replacement has no effect on the traffic using that component.

## Examples

> The hardware guide describes the module as hot-swappable.

> Follow the device procedure before replacing the module.
