# network device chassis

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The structural housing that contains a network device’s components.

## Usage and distinctions

A chassis may be fixed or modular; supported components depend on the product.

## Examples

> The chassis supports multiple line cards.

> Check the chassis model before ordering spare parts.
