# wireless access point

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network device that provides wireless connectivity to client devices.

## Usage and distinctions

Abbreviation: AP. An access point is not necessarily a standalone router; deployment modes vary.

## Examples

> The access point connects wireless clients to the network.

> Check the access point’s uplink and power source.
