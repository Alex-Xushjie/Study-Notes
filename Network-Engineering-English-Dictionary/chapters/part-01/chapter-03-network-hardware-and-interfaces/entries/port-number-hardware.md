# physical port number

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A label or identifier used to distinguish a physical port on equipment.

## Usage and distinctions

A physical port number is not the same as a TCP or UDP port number.

## Examples

> Connect the cable to physical port 12.

> Verify the port number against the front-panel label.
