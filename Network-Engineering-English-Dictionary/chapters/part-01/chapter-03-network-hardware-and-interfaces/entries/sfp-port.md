# SFP port

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A socket on network equipment designed for a compatible SFP-family module.

## Usage and distinctions

SFP-family sockets and modules differ in supported speeds and capabilities. Compatibility must be checked for the specific device.

## Examples

> The uplink uses an SFP port.

> Check which module types the port supports.
