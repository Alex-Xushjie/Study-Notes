# link up

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A state indicating that an interface has an operational physical link.

## Usage and distinctions

Link up does not by itself confirm correct VLANs, routing, policy, or application reachability.

## Examples

> The interface reports link up.

> Verify end-to-end connectivity after the link comes up.
