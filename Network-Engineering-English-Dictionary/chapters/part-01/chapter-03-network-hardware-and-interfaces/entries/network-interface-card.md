# network interface card

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A hardware adapter that provides a network interface for a host.

## Usage and distinctions

Abbreviation: NIC. Network interfaces may also be integrated into a motherboard rather than provided as a separate card.

## Examples

> The server’s network interface card has two ports.

> Check the adapter model and driver version.
