# interface description

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An administrative text label associated with a network interface.

## Usage and distinctions

A description is documentation and does not itself prove the physical connection.

## Examples

> The interface description identifies the remote device.

> Update the description after moving the connection.
