# link down

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A state indicating that an interface does not currently have an operational physical link.

## Usage and distinctions

A down link is a symptom; it does not by itself identify the cause.

## Examples

> The uplink is down.

> Check the interfaces, media, and transceivers at both ends.
