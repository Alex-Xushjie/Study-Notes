# network interface

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A physical or logical connection point through which a device sends or receives network traffic.

## Usage and distinctions

An interface may be physical, such as an Ethernet port, or logical, such as a VLAN interface.

## Examples

> The interface is administratively enabled.

> Check the interface status and counters.
