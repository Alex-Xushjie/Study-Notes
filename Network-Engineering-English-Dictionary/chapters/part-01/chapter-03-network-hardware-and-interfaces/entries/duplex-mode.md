# duplex mode

**Network engineering term** · Chapter 03

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The mode describing whether an interface can transmit and receive simultaneously.

## Usage and distinctions

Full duplex supports simultaneous transmission and reception. Settings and negotiation behavior depend on the Ethernet interface.

## Examples

> Both ends of the link operate in full-duplex mode.

> Check the speed and duplex settings on both ends.
