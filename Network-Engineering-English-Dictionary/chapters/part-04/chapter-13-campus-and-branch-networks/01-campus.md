## Key terms

| Word | Meaning |
| --- | --- |
| [access layer](entries/access-layer.md) | The layer that connects endpoint devices. |
| [distribution layer](entries/distribution-layer.md) | The layer that aggregates access connections. |
| [core layer](entries/core-layer.md) | The layer connecting major network sections. |
| [branch network](entries/branch-network.md) | A site network connected to the broader organization. |

## Examples and usage

> The access layer connects user workstations and access points.

> The distribution layer aggregates the access switches.

> The core layer connects the distribution blocks.

> The branch connects to headquarters over the WAN.
