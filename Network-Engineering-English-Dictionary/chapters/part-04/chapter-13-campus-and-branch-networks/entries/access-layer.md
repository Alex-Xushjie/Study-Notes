# access layer

**Network engineering term** · Chapter 13

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The part of a network architecture that connects end devices to the network.

## Usage and distinctions

Access is a functional role. A collapsed design may combine access and other functions differently.

## Examples

> The access layer connects user workstations and access points.

> Check the access switch and endpoint port.
