# core layer

**Network engineering term** · Chapter 13

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The part of a hierarchical network design that provides connectivity between major network sections.

## Usage and distinctions

Core is an architectural role; a collapsed core combines functions in fewer layers.

## Examples

> The core layer connects the distribution blocks.

> Review the core path and its redundancy.
