# collapsed core

**Network engineering term** · Chapter 13

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A design that combines core and distribution functions in a shared layer or devices.

## Usage and distinctions

Collapsing layers changes topology and failure domains; it does not mean the network has no core function.

## Examples

> The smaller campus uses a collapsed core.

> Confirm which devices perform routing and aggregation.
