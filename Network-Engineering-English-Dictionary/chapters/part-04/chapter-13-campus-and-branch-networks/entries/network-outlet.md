# network outlet

**Network engineering term** · Chapter 13

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A wall- or furniture-mounted connection point for network cabling.

## Usage and distinctions

The outlet label should correspond to the cable record; connector type and link category must be verified.

## Examples

> The workstation connects to the network outlet.

> Trace the outlet to the patch panel.
