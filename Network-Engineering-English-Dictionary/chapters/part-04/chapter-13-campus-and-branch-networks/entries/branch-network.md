# branch network

**Network engineering term** · Chapter 13

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A network serving a remote office or site connected to a broader organization.

## Usage and distinctions

A branch can have local switching, wireless, security, and Internet access depending on its design.

## Examples

> The branch network connects to headquarters over the WAN.

> Check local services as well as the WAN link.
