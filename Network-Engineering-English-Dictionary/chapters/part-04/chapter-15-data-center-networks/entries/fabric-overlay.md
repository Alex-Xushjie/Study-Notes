# fabric overlay

**Network engineering term** · Chapter 15

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logical network constructed over an underlying data center transport network.

## Usage and distinctions

An overlay commonly uses encapsulation; it does not automatically provide encryption.

## Examples

> The overlay extends the tenant network across the fabric.

> Check overlay state and the corresponding underlay path.
