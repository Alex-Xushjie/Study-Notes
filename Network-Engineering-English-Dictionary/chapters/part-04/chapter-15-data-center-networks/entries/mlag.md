# multi-chassis link aggregation

**Network engineering term** · Chapter 15

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A design in which multiple physical devices participate in a logical link-aggregation arrangement.

## Usage and distinctions

Abbreviation: MLAG. Implementations, control mechanisms, and limitations differ by vendor.

## Examples

> The server uses an aggregated connection to two leaf switches.

> Check the multi-chassis peer state and member links.
