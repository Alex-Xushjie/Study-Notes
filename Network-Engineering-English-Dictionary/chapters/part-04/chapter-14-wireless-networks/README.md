## Say it at work

> Which SSID and BSSID was the client using when the issue occurred?

> Please record the time, location, signal reading and client model.

> Does the client fail association, authentication or address assignment?

> The signal is strong, but the radio has high airtime utilization.

## Quick review

1. Does one SSID uniquely identify an access point?
2. Does strong signal guarantee adequate capacity?
3. Are association and IP address assignment the same step?
4. Can all sites use the same channels and transmit powers?

**Answers**

1. No; multiple access points can advertise the same SSID.
2. No; airtime use, interference, and client load also matter.
3. No; they are distinct stages.
4. No; applicable regulatory rules and equipment support vary.
