# wireless association

**Network engineering term** · Chapter 14

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The 802.11 process and state by which a client joins a basic service set.

## Usage and distinctions

Association, authentication, authorization, and IP address assignment are distinct stages.

## Examples

> The client associates with the access point.

> Check whether association succeeds before examining IP configuration.
