# service set identifier

**Network engineering term** · Chapter 14

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An identifier used to name a wireless network.

## Usage and distinctions

Abbreviation: SSID. One SSID can be provided by multiple access points; it does not uniquely identify a radio.

## Examples

> Select the corporate SSID on the client.

> Confirm that the expected SSID is available.
