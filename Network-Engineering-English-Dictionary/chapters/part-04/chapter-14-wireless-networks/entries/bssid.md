# basic service set identifier

**Network engineering term** · Chapter 14

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An identifier for a basic service set in an 802.11 wireless network.

## Usage and distinctions

Abbreviation: BSSID. It is commonly represented as a MAC address; one AP may advertise multiple BSSIDs.

## Examples

> The client is associated with the BSSID of the nearby access point.

> Record the BSSID when investigating roaming.
