# cloud virtual machine

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A software-defined compute instance running in a cloud environment.

## Usage and distinctions

Abbreviation: VM. A VM’s guest configuration and cloud network policy both affect reachability.

## Examples

> The virtual machine is deployed in the application subnet.

> Verify the VM’s network interface and firewall settings.
