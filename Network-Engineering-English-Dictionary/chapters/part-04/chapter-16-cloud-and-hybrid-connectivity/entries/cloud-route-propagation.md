# cloud route propagation

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

The distribution of learned routes into a cloud route table or routing service.

## Usage and distinctions

Propagation does not guarantee selection; precedence and filtering rules are provider-specific.

## Examples

> The gateway propagates the on-premises prefixes.

> Check whether the routes are propagated into the correct table.
