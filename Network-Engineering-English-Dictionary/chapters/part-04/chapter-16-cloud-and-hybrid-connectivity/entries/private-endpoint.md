# cloud private endpoint

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A private network address or attachment used to reach a supported service without a public service endpoint path.

## Usage and distinctions

Provider-specific implementations differ; the precise traffic path and service coverage must be verified.

## Examples

> The application reaches the service through a private endpoint.

> Check private DNS resolution and endpoint policy.
