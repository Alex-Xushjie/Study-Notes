# cloud network ACL

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A set of network filtering rules applied at a cloud network boundary such as a subnet.

## Usage and distinctions

Cloud ACL capabilities and statefulness are provider-specific and should not be assumed identical to security groups.

## Examples

> The network ACL allows the required traffic.

> Check rule order and return traffic requirements.
