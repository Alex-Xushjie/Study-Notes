# cloud transit gateway

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A managed or virtual connectivity component used to connect multiple networks through a central routing domain.

## Usage and distinctions

Names, routing features, and service limits differ by provider; the term is used generically here.
