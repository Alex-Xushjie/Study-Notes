# virtual private cloud

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logically isolated virtual network in a cloud provider environment.

## Usage and distinctions

Abbreviation: VPC. Specific behavior depends on the provider and service.
