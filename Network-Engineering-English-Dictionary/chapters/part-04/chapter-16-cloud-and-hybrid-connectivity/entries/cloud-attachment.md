# transit attachment

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A connection between a network resource and a transit routing service.

## Usage and distinctions

Attachment lifecycle and route propagation behavior are provider-specific.
