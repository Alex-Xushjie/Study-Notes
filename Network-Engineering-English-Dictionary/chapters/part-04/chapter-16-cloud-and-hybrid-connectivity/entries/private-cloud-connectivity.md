# private cloud connectivity

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A connectivity service providing a private network path to a cloud provider.

## Usage and distinctions

Service names and actual path properties vary; private connectivity does not automatically imply encryption.

## Examples

> The data center connects to the cloud using private connectivity.

> Confirm the provider handoff and BGP configuration.
