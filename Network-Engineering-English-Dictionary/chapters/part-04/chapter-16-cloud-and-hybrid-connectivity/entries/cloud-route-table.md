# cloud route table

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A set of routes used by a cloud platform to direct traffic for a virtual network or subnet.

## Usage and distinctions

Association, precedence, and propagation rules are provider-specific.

## Examples

> The subnet uses a route table with a default route to the firewall.
