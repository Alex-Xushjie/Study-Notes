# cloud security group

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A virtual firewall policy associated with cloud network interfaces or workloads.

## Usage and distinctions

Statefulness and rule behavior vary by provider; verify the relevant service documentation.

## Examples

> The security group allows the application port from the load balancer.

> Check both inbound and outbound rules.
