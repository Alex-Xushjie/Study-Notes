# cloud region

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A geographic area in which a cloud provider operates infrastructure and offers services.

## Usage and distinctions

Services, boundaries, and cross-region connectivity differ by provider.

## Examples

> The workload runs in a specified cloud region.

> Verify that the network resources are in the intended region.
