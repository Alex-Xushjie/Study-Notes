# availability zone

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A provider-defined isolated location or failure domain within a cloud region.

## Usage and distinctions

Abbreviation: AZ. The definition and resilience characteristics depend on the provider.

## Examples

> The application uses resources in multiple availability zones.

> Check whether the gateway and workloads are in the expected zones.
