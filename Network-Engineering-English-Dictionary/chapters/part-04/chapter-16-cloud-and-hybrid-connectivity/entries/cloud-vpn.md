# cloud VPN

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A VPN connection used to link a cloud network to another network or environment.

## Usage and distinctions

A configured VPN tunnel does not itself guarantee application reachability.

## Examples

> The cloud VPN connects the branch to the virtual network.

> Check tunnel state, routes, and selectors.
