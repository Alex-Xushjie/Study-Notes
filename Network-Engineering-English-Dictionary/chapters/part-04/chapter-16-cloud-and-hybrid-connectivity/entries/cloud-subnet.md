# cloud subnet

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logical subdivision of a cloud virtual network address space.

## Usage and distinctions

Cloud subnet behavior may differ from traditional on-premises VLAN and broadcast-domain assumptions.

## Examples

> The workload is deployed in a private cloud subnet.

> Check the subnet’s route table and security rules.
