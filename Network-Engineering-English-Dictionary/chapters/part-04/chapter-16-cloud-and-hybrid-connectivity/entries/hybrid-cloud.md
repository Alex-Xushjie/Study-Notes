# hybrid cloud

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An architecture combining cloud resources with on-premises or other environments.

## Usage and distinctions

Hybrid refers to the combined environments, not a particular transport or security method.

## Examples

> The hybrid cloud connects the data center to the cloud network.

> Check routing and security on both sides.
