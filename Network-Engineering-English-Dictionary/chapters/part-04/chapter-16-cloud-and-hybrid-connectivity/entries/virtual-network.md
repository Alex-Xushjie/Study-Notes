# virtual network

**Network engineering term** · Chapter 16

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A logically isolated network constructed in a virtualized or cloud environment.

## Usage and distinctions

Names such as VPC and VNet are provider-specific; their capabilities and limits are not identical.

> The virtual network contains two application subnets.
