## Key terms

| Word | Meaning |
| --- | --- |
| [cloud virtual machine](entries/cloud-virtual-machine.md) | A software-defined compute instance in the cloud. |
| [cloud network interface](entries/cloud-network-interface.md) | A virtual network attachment for a workload. |
| [cloud security group](entries/cloud-security-group.md) | A policy controlling traffic to or from cloud resources. |
| [cloud route table](entries/cloud-route-table.md) | Routes directing traffic for cloud resources. |
