## Key terms

| Word | Meaning |
| --- | --- |
| [on-premises network](entries/on-premises-network.md) | A network operated at an organization’s site. |
| [private cloud connectivity](entries/private-cloud-connectivity.md) | A private network path to a cloud provider. |
| [virtual network](entries/virtual-network.md) | A logical network in a cloud environment. |
| [cloud subnet](entries/cloud-subnet.md) | A subdivision of a cloud network address space. |

## Examples and usage

> The on-premises network connects to the cloud through a gateway.

> Confirm the provider handoff and BGP configuration.

> Check the virtual network address space.

> Verify the subnet route table and security rules.
