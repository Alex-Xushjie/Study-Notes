# Which option are we discussing?

**Professional expression** · Chapter 29

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A question used to identify the alternative being considered.

## Usage and distinctions

Name the options when possible to avoid ambiguity.

## Examples

> Which option are we discussing: the single-provider or dual-provider design?

> Which option are we discussing for the branch?
