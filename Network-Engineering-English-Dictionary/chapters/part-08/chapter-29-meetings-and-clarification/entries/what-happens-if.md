# What happens if …?

**Professional expression** · Chapter 29

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A question exploring the consequences of a specified condition.

## Usage and distinctions

Specify the failure or scenario rather than asking about resilience in general.

## Examples

> What happens if the primary circuit fails?

> What happens if the authentication server is unavailable?
