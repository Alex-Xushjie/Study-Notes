# If I understand correctly, …

**Professional expression** · Chapter 29

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression used to restate an understanding and invite correction.

## Usage and distinctions

Follow with a concise restatement; ask for confirmation if needed.

## Examples

> If I understand correctly, the change affects one branch.

> If I understand correctly, the provider owns the circuit.
