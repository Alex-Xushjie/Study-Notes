# What is the current state of …?

**Professional expression** · Chapter 29

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A question asking for the present condition of a system or task.

## Usage and distinctions

Request a timestamp or evidence when the state may change quickly.

## Examples

> What is the current state of the backup circuit?

> What is the current state of the change request?
