# Could you run a test?

**Professional expression** · Chapter 31

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A request for the other party to perform a defined test.

## Usage and distinctions

Specify the test scope, timing, authorization, and desired evidence.

## Examples

> Could you test the circuit to the demarcation point?

> Could you run the agreed loopback test during the window?
