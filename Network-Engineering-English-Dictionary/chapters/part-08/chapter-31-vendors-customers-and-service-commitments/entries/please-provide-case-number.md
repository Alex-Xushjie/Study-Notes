# Please provide the case number.

**Professional expression** · Chapter 31

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A request for a support case or ticket reference.

## Usage and distinctions

Use the exact reference when following up across teams.

## Examples

> Please provide the vendor case number.

> Please provide the provider ticket reference for this circuit.
