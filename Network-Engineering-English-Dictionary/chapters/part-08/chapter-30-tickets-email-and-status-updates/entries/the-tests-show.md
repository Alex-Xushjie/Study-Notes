# The tests show …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A statement reporting a test observation.

## Usage and distinctions

Specify test source, destination, protocol, time, and limitations where relevant.

## Examples

> The tests show that the gateway is reachable.

> The tests show packet loss from the affected branch.
