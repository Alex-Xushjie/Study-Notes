# The following action is required: …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A statement introducing a specific required action.

## Usage and distinctions

Specify the responsible person and deadline if known.

## Examples

> The following action is required: approve the maintenance window.

> The following action is required: verify the circuit ID.
