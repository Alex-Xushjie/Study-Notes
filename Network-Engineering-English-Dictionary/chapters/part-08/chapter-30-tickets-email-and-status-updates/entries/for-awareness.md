# For awareness, …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression introducing information that the recipient should know.

## Usage and distinctions

State clearly if any recipient action is required.

## Examples

> For awareness, the backup link is under test.

> For awareness, the provider has opened a support case.
