# Please find attached …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A formal expression referring to an attached item.

## Usage and distinctions

Use only when the item is actually attached; “I have attached …” is often more direct.

## Examples

> Please find attached the revised topology diagram.

> Please find attached the test results.
