# The issue started at …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A statement reporting the known or estimated start time.

## Usage and distinctions

Distinguish a verified start time from a first alert or estimate.

## Examples

> The issue started at approximately 09:10 UTC.

> The first user report was received at 09:10 UTC.
