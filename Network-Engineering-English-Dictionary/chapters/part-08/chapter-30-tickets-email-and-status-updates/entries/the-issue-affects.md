# The issue affects …

**Professional expression** · Chapter 30

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

A statement identifying affected users, services, or locations.

## Usage and distinctions

Use verified scope and update it if the investigation changes it.

## Examples

> The issue affects users at the Shanghai branch.

> The issue affects access to the application from one subnet.
