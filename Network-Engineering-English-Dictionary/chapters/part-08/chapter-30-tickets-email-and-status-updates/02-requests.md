## Key terms

| Word | Meaning |
| --- | --- |
| [Please provide …](entries/please-provide.md) | Request a specific item or detail. |
| [Could you share …?](entries/could-you-share.md) | Politely request information or a document. |
| [According to the logs, …](entries/according-to-the-logs.md) | Attribute an observation to log evidence. |
| [The tests show …](entries/the-tests-show.md) | Report a test observation. |

## Examples and usage

> Please provide the circuit ID and affected site.

> Could you share the latest topology diagram?

> According to the logs, the interface changed state at 09:15 UTC.

> The tests show that the gateway is reachable.
