# The current design uses …

**Professional expression** · Chapter 32

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression describing the existing or proposed architecture.

## Usage and distinctions

Identify the version or time when the design can change.

## Examples

> The current design uses two access switches and one distribution layer.

> The current design uses a VPN for branch connectivity.
