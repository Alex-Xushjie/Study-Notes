# If this component fails, …

**Professional expression** · Chapter 32

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression describing a failure scenario and expected behavior.

## Usage and distinctions

Distinguish expected behavior from a verified test result.

## Examples

> If the primary circuit fails, traffic should use the backup path.

> If the active gateway fails, the standby should take over.
