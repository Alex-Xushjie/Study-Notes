# An alternative is to …

**Professional expression** · Chapter 32

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression introducing another candidate approach.

## Usage and distinctions

Compare alternatives against the same criteria.

## Examples

> An alternative is to use a single provider with a backup VPN.

> An alternative is to keep the current topology and upgrade the uplinks.
