# This depends on …

**Professional expression** · Chapter 32

[Chapter](../README.md) · [English index](../../../../indexes/ENGLISH-INDEX.md)

## Definition

An expression describing a condition necessary for an outcome.

## Usage and distinctions

Name the dependency and whether it is confirmed.

## Examples

> This depends on the provider delivering diverse paths.

> This depends on the application supporting the new address.
