## Key terms

| Word | Meaning |
| --- | --- |
| [The requirement is to …](entries/the-requirement-is.md) | State a verifiable need. |
| [One option is to …](entries/one-option-is.md) | Introduce a possible approach. |
| [An alternative is to …](entries/an-alternative-is.md) | Introduce another candidate approach. |
| [The trade-off is …](entries/the-trade-off-is.md) | Explain a compromise between objectives. |

## Examples and usage

> The requirement is to maintain branch connectivity during a link failure.

> One option is to add a second circuit.

> An alternative is to use a backup VPN.

> The trade-off is higher cost for greater path diversity.
