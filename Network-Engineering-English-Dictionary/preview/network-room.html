Network Engineering English01 / Rooms & Facilities

Inside a network room

A telecommunications room brings equipment, cabling and power together. Look at the picture, then match each number with its name below.

Picture words

1
equipment rack

A frame for mounting network equipment.

Learn more

A rack provides mounting positions; a cabinet adds an enclosure.

2
equipment cabinet

An enclosure that houses equipment.

Learn more

Cabinets commonly have doors, side panels and mounting rails.

3
cable tray

A structure that supports cables along a route.

Learn more

Overhead trays carry cable bundles between room locations.

4
uninterruptible power supply

A system that provides power during an interruption.

Learn more

Abbreviation: UPS. Runtime depends on the load and stored energy.

5
patch panel

A panel of organized cable connection points.

Learn more

A patch panel is passive; it does not switch Ethernet frames.

6
network switch

A device that connects ports and forwards traffic.

Learn more

The switch can connect to cable terminations through patch cords.

SAY IT AT WORK

“The switch is mounted below the patch panel.”

“The cables run along the overhead cable tray.”

“Could you confirm the rack and U position?”

“The UPS supplies power during an interruption.”
