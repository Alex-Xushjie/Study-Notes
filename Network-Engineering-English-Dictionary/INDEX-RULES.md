# Index Rules

[Home](README.md) · [English index](indexes/ENGLISH-INDEX.md)

Maintain one main file per concept, using lowercase ASCII kebab-case filenames. Give every entry a stable ID independent of its chapter location. Record aliases as an array and link them to the main entry without duplicating the definition. Distinguish different meanings of the same abbreviation.

Sort headwords and aliases alphabetically without case sensitivity. Retain standard capitalization in the display. Use relative links; update the chapter list, table of contents, index, and file tree when adding or moving entries. Count complete entries only, not templates or chapter placeholders.
